หุ้นไทย ×1 ฿ S50 ×200 $ หุ้น US ×1 $ XAU 1 lot ×100 $ XAU 0.1 lot ×10 $ MES ×5 $ ES ×50 $
เขียนตอนนี้ ตอนที่ยังไม่มีเงินอยู่ในตลาดและยังคิดตรง — ไม่ใช่ตอนที่ราคาลงแล้วกำลังหาเหตุผลถือต่อ

Sat.A — 1R มาจากคะแนน Growth Gate ของหุ้นตัวนั้นใน Watchlist: 8-9 → 1.25% · 6-7 → 1.00% · 4-5 → 0.75% · ≤3 → 0.50% (ช่อง "Sat.A — 1R %" ด้านบนใช้เป็นหน่วยอ้างอิงของ Portfolio heat เท่านั้น ไม่ได้กำหนดขนาดไม้)
Setup — Acc/Dist ×1.00 · PP ×0.50 · ไม่มีบันไดไม้ (base/add-on) แล้ว ทุกไม้เป็นไม้เดียว
แผนที่ธีม (RRG) — แหล่งราคา
ใช้ดึงราคาปิดรายวันมาคำนวณ RRG ให้อัตโนมัติ · สมัครฟรีที่ twelvedata.com — ใช้วันละ ~19 เครดิตจากโควตาฟรี 800/วัน
key ถูกเก็บใน Firestore ของคุณเอง ซิงก์ข้ามเครื่อง · ใครก็ตามที่เปิด dashboard นี้ได้จะเห็น key ได้ ถ้าหลุดให้ไป regenerate ใหม่
Sat.B — Default Volatility (จุด/point)
ใช้เป็นพื้นระยะขั้นต่ำตอนคำนวณขนาดไม้: ระยะที่ใช้ = MAX(ระยะ SL จริง, Default Volatility)
SL กว้างกว่าค่านี้ → ใช้ SL จริง ไม้เล็กลงตามปกติ · SL แคบกว่าค่านี้ → ยังใช้ค่านี้คำนวณ กันไม้ใหญ่เกินจากการตั้ง stop ชิดกว่าที่สินค้านั้นแกว่งจริง
เช่น RPT 2% · XAUUSD 30p · ตั้ง SL 20p → ยังคิดที่ 30p (ไม้เล็กกว่าที่ 20p จะให้) แต่ถ้าตั้ง SL 40p → คิดที่ 40p
