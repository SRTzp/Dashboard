# LN3 — เทสเก่าที่ถูกแก้ความคาดหวัง

ผลรันเต็มชุด (base + phase 1–88 ทีละชุด): ดูรายงานท้ายงาน · ล้มหลอกที่ทราบ (p3 วันอาทิตย์ · p6 'ยกเลิก 20' · p13 ไม่มี backup-pre-UI1) ไม่ได้แก้

- ไม่มีเคสถูกลบ · ไม่มีเคสถูกทำให้อ่อนลง · ชุดเก่าทั้งหมดรันกับ "แบบเดิม" (ff_stub seed `ln1_plan_view=legacy`) → ผ่านโดยไม่แก้
- แก้เฉพาะ phase80 / phase81 (เทสของโหมด Lean รอบ LN1/LN2 ที่ brief LN3 สั่งเปลี่ยนพฤติกรรม/ข้อความ) · จำนวนเคสเท่าเดิม (80 = 78 เคส · 81 = 68 เคส)
