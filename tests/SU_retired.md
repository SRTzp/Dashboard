# SU — เคสที่แก้ความคาดหวัง (tests)

ไม่มีเคสที่ลบหรือเลิกใช้ — ทุกเคสยังรันและต้องผ่าน (จำนวนเคสเท่าเดิมทุกชุด) · เพิ่มชุดใหม่ phase30 (56 เคส)

| ชุด | เคส | เดิม | ใหม่ | เหตุผล |
|---|---|---|---|---|
| phase3 | การ์ดร่าง Setup 0/3 (×2 viewport) | ข้อความ `Setup 0/3` + `ต่ำกว่า 65% = นอกแผน` | `ต่ำกว่า 65% = Setup ไม่ครบ` (ชื่อเคสแก้ตาม) | Setup ไม่ถึงเกณฑ์ไม่ใช่นอกแผนแล้ว (brief ข้อ 4) |
| phase3 | บันทึก order Setup ไม่ครบ (×2) | `unplanned is True or offplan is True or True` (เงื่อนไขว่าง ผ่านเสมอ) | `setup_incomplete is True and unplanned is False` | brief ข้อ 2 · เปลี่ยนจากเงื่อนไขว่างเป็นการตรวจจริง |
| phase4 | v3on: setup ยังไม่ครบ → แค่ข้อความเตือน (×2) | ค้นข้อความ `ต่ำกว่า 65% = นอกแผน` | ค้น `ต่ำกว่า 65% = Setup ไม่ครบ` | ข้อความหน้างานเปลี่ยน (brief ข้อ 4) |
| phase5 | Setup 0/3 → เตือน (×2) | `Setup 0/3 · ต่ำกว่า 65% = นอกแผน` | `Setup 0/3 · ต่ำกว่า 65% = Setup ไม่ครบ` | เหมือนข้างบน |
| phase5 | Setup 1/3 → ไม่ผ่าน (×2) | `Setup 1/3 · ต่ำกว่า 65% = นอกแผน` | `Setup 1/3 · ต่ำกว่า 65% = Setup ไม่ครบ` | เหมือนข้างบน |

phase 12/15/17/18/20/27 ตรวจแล้ว: ไม่มีเคสที่คาด "นอกแผน" จาก Setup ไม่ครบ (ผ่านทั้งหมดโดยไม่ต้องแก้)
