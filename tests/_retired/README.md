How the reason was decided: the suite was run on the base commit (origin/main 2739856) and again after the shared fixes (no real network, obsolete backup-file checks removed). The first failing step is quoted. The job is the one whose brief / report / commit describes the change (LN4-report §0, PB1-brief §1/§5, WL1-brief §1, RE1-C1/C2/D summaries). **The reason is per group (screen), checked against the first failing step of each suite — it was not re-derived check by check; a suite that still has a valid check should be ported into a current suite, not revived here.**

`lib_*.py` files in `tests/` are the launchers / fixtures of retired suites that current suites still import; their own checks are retired.
