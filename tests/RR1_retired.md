# RR1 — เทสเก่าที่แก้ความคาดหวัง

ไม่มีเคสเก่าที่ต้องแก้ความคาดหวัง (ไม่ลบ ไม่ทำให้อ่อนลง)

- รอบแรกลองจองกล่องภาพ 16:9 ตายตัว → ชน phase59 (ESC1) / phase67 ที่ต้องการ "สูงตามสัดส่วนภาพจริง" จึงเปลี่ยนวิธี: จองที่ 16:9 ก่อนโหลด แล้วใช้สัดส่วนจริงทันทีที่ภาพโหลด (จำสัดส่วนต่อ URL ไว้ วาดใหม่รอบหลังไม่ขยับ) · เทสเก่าผ่านโดยไม่แก้
- ไม่พบเทสที่เรียก `satV3Render()` แล้วคาดว่า DOM เปลี่ยนทั้งที่ข้อมูลไม่เปลี่ยน → ไม่ต้องใช้ `satV3Render({force:true})` ในเทสเก่า
- ข้อจำกัดที่ตั้งใจ: ภาพที่ไม่ใช่ 16:9 และ "โหลดครั้งแรก" จะปรับความสูงครั้งเดียวตอนโหลดเสร็จ (รู้สัดส่วนจริงต่อเมื่อโหลดแล้ว)

## RR1fix
- phase59 เคส 3 (390px) 'ช่อง XAU ไม่มีกราฟสูงเท่าก่อน VW1': เปลี่ยนจากเพดาน px ตายตัว (6+22) เป็นวัดจำนวนบรรทัดด้วย line-height จริง (computed) · ส่วนเกินจากขึ้นบรรทัดใหม่ ≤ 1 บรรทัด · ขอบล่าง/เงื่อนไข 1440 และเคสอื่นเท่าเดิม
