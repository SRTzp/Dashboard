VW1 — Firestore rule ที่ต้องเพิ่มก่อนขึ้นเว็บ (โน้ต 3 มุม Event · Fund. · Tech ของหุ้น)

เปิด Firebase Console → Firestore Database → Rules แล้วเพิ่มบล็อกนี้ในกลุ่ม match /databases/{database}/documents
(ใกล้ ๆ กับ rule ของ ideas / prices / watchlist เดิม) แล้วกด Publish:

match /users/{uid}/stockNotes/{doc} {
  allow read, write: if request.auth != null && request.auth.uid == uid;
}

- ยังไม่เพิ่ม rule: แอปทำงานปกติทุกส่วน แต่จุดโน้ตในการ์ดหุ้น/แถว Candidate จะแสดง
  "ยังอ่านโน้ตไม่ได้ (ต้องเพิ่ม Firestore rule stockNotes)"
