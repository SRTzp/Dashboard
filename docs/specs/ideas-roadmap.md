## 2. ขอบเขตแต่ละรอบ (ย่อ · รายละเอียดอยู่ใน spec)

**ID1 — แท็บ Ideas (อ่านอย่างเดียว)**
- Firestore `users/{uid}/ideas/{id}` + rules (สำเนา rules เก็บใน repo)
- หน้า Watch: pills `[Watchlist] [Ideas] [Candidates]` · Tab / Shift+Tab วน 3 หน้า · ↑↓ ←→ · Esc มือถือ · `[ ]` กรองสถานะ · อัปเดตหน้า `?`
- รายการไอเดีย: จุดสี · สถานะ · วันที่ (⚠ เกิน 30 วัน)
- การ์ด 5 แท็บ: สรุป · กลไก · หลักฐาน · Value chain (ticker ในกล่อง) · บริษัท (ดูได้ ยังกดส่งต่อไม่ได้)
- 📥 Import (ตรวจ `schema === "idea@1"` · ≤200KB · Import ซ้ำไม่ทับ status/rank/state ที่ผู้ใช้ตั้ง · log append) · ⋯ Export JSON
- ลบ: ร่าง = ลบได้ทันที · อื่น ๆ = ต้องพักก่อน → ลบจากหน้าพัก + ยืนยัน + ดาวน์โหลด JSON สำรองอัตโนมัติ
- ผู้ใช้แก้ได้: สถานะไอเดีย · ติ๊กส่วน value chain (`pick`) · ลำดับ/สถานะบริษัท
- กติกาบังคับ: ตั้ง "พร้อมส่งต่อ" ไม่ได้ถ้าไม่ผ่าน 4 ข้อ (ขัดแย้ง ≥1 · สัญญาณพัก ≥1 · บริษัทศึกษา ≥1 · ไม่มีข้อที่ขาดระดับ "ต้องรู้" เปิดอยู่)

**ID2 — เชื่อม Watchlist / Candidates**
- Candidates = บริษัทจาก Ideas ที่ยังไม่อยู่ Watchlist · **เลิกอ่าน collection `research`** (ไม่ลบข้อมูล)
- ป้าย `▲ ▼ ?` บรรทัดเดียวบนแถว Watchlist + Candidates · ส่วน "ไอเดียที่เกี่ยวข้อง" ในการ์ดหุ้น · ปุ่ม 📊 รายได้แยกส่วน (ลิงก์ TradingView)
- ปุ่ม → Watchlist (บังคับมี `relevance_src`) · คัดลอก Handoff · Handoff (update) สำหรับหุ้นฝั่ง ▼ ที่ถืออยู่
- asset อื่น 1 บรรทัดในแท็บสรุป → เปิด Playbook ในแท็บ Flow

**ID3 — หาไอเดีย + ตอบข้อที่ขาด**
- ＋ ไอเดีย (ร่าง · 4 ช่อง) · ⋯ คัดลอกคำสั่ง scan
- 📝 ตอบข้อที่ขาด (เลือกหลายข้อ) · ปิดเป็น "หาไม่ได้" ในแอป
- 📋 จับคู่ list: ชั้น 1 ในแอป · คัดลอกคำสั่ง match · Import `idea-match@1` · แถว "กลุ่มยังไม่มีไอเดีย" (≥3 ตัว · ซ่อน 30 วัน)

**ID4 — แท็บวันนี้**
