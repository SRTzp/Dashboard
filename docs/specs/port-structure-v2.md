# โครงพอร์ต v2 — Core 70 / Satellite 30 (Main Swing + Tactical Swing)

> สรุปจากการคุย 16 ต.ค. 2026 · แทนโครง 70/20/10 (Core/Sat/Option) เดิม · ไม่มี Port Option แยก · ใช้ต่อบัญชี (main / Family แยกกัน)
> ตัวเลขเป็นกรอบสำหรับทดลอง 1–2 เดือน แล้วปรับตาม Journal · ไม่ใช่การรับประกันขาดทุนสูงสุด (Gap / Slippage อาจเสียเกินแผน)

## 0. Objective (ใช้ตัดสินทุกเรื่อง)
**Simple · Clear · ใช้งานง่าย · Effective** — ขั้นตอนเดิม (Macro → เลือก Asset → Bias → วางแผน) · แผนหนึ่งใบกรอกแค่ **Setup · ทิศ · Entry · SL** (TP คิดให้) · ตัวเลข Risk/TF/Setup ตั้งครั้งเดียวในตั้งค่า · แอปคิดขนาดไม้ + เพดาน + เตือน/บล็อกให้ ผู้ใช้ไม่ต้องจำกติกา

## 1. โครงสร้าง

| ส่วน | % พอร์ตรวม | สินค้า | TF | ถือ | หน้าที่ |
|---|---:|---|---|---|---|
| **Core** | 70% | หุ้น US/TH (+ สินทรัพย์ไม่มี Leverage) | Week | 3–12+ เดือน | Run Trend ระยะยาว |
| **Main Swing** | 21% (70% ของ Satellite) | Futures: XAUUSD · BTC · S50 · Brent | Week / Day | จนสัญญาณจบรอบ | จับรอบกลับตัว (Macro + Trend ช่วงออกข้าง) |
| **Tactical Swing** | 9% (30% ของ Satellite) | Futures ชุดเดียวกัน · **เฉพาะ Asset ที่เลือกประจำสัปดาห์** | 30m | สั้น ตามกรอบ | ตาม Trend ใกล้กรอบราคา · เร่งกำไร · Hedge ช่วง Bias Neutral |

แต่ละส่วนออกตามกฎของตัวเอง — Tactical ออก ≠ Main ต้องออก

### ขั้นตอน (เหมือนเดิม · ใช้ง่าย)
Macro → เลือก Asset ประจำสัปดาห์ 1–3 ตัว → ตั้ง Bias สัปดาห์ → วางแผน Main และ/หรือ Tactical (ปุ่ม `Main | Tactical`)

| | Main Swing | Tactical |
|---|---|---|
| ใช้เมื่อ | Macro เริ่มเปลี่ยน + Trend ออกข้าง (Neutral) | Trend ชัด + ใกล้กรอบราคาสำคัญ · หรือ Hedge ตอน Neutral · **เฉพาะ Asset ที่เลือก** |
| TF (กรอกเอง · ค่าเริ่มในตั้งค่า) | ค่าเริ่ม `D` | ค่าเริ่ม `30m` |
| Setup (ป้าย · รายการแยกต่อส่วน · แก้ในตั้งค่า) | ค่าเริ่ม `Break EMA20` · `Break Weekly PoC` | ค่าเริ่ม `Break EMA50` · `Break Daily PoC` |
| เงื่อนไขเสริม | ช่องข้อความสั้น เช่น `Break Point 4,180` | เหมือนกัน |
| กรอกในแผน | **ทิศ · Entry · SL** (ไม่มี Break/Pullback/Vol แล้ว — เงื่อนไขชัดจาก Setup) | **ทิศ · Entry · SL** |
| ออก | TP กรอกเองได้ (ไม่บังคับ) · Trend Shift | คิดให้: TP1 **2R 50%** + TP2 **3R** ที่เหลือ (ตั้งค่าได้) |
| Risk / ขนาด | RPT จากตั้งค่า (ค่าเริ่ม 2%) · แอปคิด lot + เพดาน | RPT จากตั้งค่า (ค่าเริ่ม 2%) · แอปคิด lot + เพดาน |

## 2. Bias (Daily EMA20)
- **ตั้ง Bias รายสัปดาห์เหมือนเดิม** (ช่อง Bias สัปดาห์ในแอป · ตั้งเอง) · ใช้ Daily EMA20 เป็นตัวช่วยตัดสิน:
  `|EMA20 − EMA20[5 แท่งก่อน]| < 0.5 × ATR(14)` → **Neutral** · มากกว่านั้น → **Long / Short** ตามทิศ EMA20 (ค่า 5 / 0.5 = ค่าเริ่มต้น ลองย้อนกับกราฟแต่ละสินค้า)
- แอปไม่ดึงราคา Sat เอง → อ่านจาก indicator TradingView (Pine "Bias EMA20 State") แล้วตั้ง Bias ในแอปเอง
- **Main เข้าไม้กลับตัวแล้ว ยังไม่เปลี่ยน Bias** → คง Neutral จน Trend เริ่มชัด แล้วค่อยเปลี่ยนเป็น Long/Short ตามทิศใหม่
- **ห้ามเปิดไม้สวน Bias (Long/Short) เหมือนเดิม** · ตอน Neutral ไม่มีทิศให้สวน

## 3. Risk ต่อดีล + เพดานมูลค่าสัญญา

| ส่วน | Risk ต่อดีล | เทียบพอร์ตรวม | เพดานมูลค่าสัญญาต่อดีล |
|---|---:|---:|---|
| Core | 1.25% ของพอร์ต Core | ≈0.875% | — (ไม่มี Leverage) |
| Main Swing | 2% ของ Main (ตั้งค่า) | 0.42% | ≤ 2 เท่าของเงิน Main |
| Tactical | 2% ของ Tactical (ตั้งค่า) | 0.18% | ≤ 4 เท่าของเงิน Tactical |

**ตั้งค่า › Sat (ต่อบัญชี · แสดง % ของพอร์ตรวมข้างช่องอัตโนมัติ) — Risk ไม่เลือกรายแผน ใช้ค่าจากตั้งค่าทั้งระบบ:**

| ค่า | ค่าเริ่ม | ตัวเลือก |
|---|---|---|
| สัดส่วน Main : Tactical | 70 : 30 | กรอกเอง |
| RPT Main / RPT Tactical | 2% / 2% | 1 · 1.25 · 1.5 · 2% (เพิ่มภายหลังได้) |
| TF ค่าเริ่ม Main / Tactical | D / 30m | กรอกเอง |
| รายการ Setup Main / Tactical | EMA20 · Weekly PoC / EMA50 · Daily PoC | เพิ่ม/ลบ/แก้ชื่อ |
| Max DD ของ Satellite (หยุดเปิดไม้ใหม่) | 20% (= 6% พอร์ตรวม) | กรอกเอง |
| เพดานมูลค่าสัญญา Main / Tactical | 2× / 4× | กรอกเอง |
| เบรก Tactical (เสียติด / DD) | 5 ไม้ / 10% | กรอกเอง |
| แผนออก Tactical | TP1 2R 50% · TP2 3R 50% | กรอกเอง |
| เพดาน Open Risk: Satellite / ต่อสินค้า / Core+Satellite | 1.2% / 0.6% / 6% | กรอกเอง |

- ขนาด = Risk ÷ ระยะ Stop · ชนเพดานมูลค่า → ลดขนาด (Risk จริงต่ำกว่าแผน) · **ห้ามขยาย Stop เพื่อให้ได้ขนาด**
- Risk นับรวมทุกไม้ในดีลเดียวกัน (เติมไม้ 50/30/20 ของ Main อยู่ใน 2% ของ Main)
- ตัวคูณ Macro ใช้กับทั้ง Main และ Tactical (สวน Macro ×0.6 · Neutral ×1.0 · ปรับได้)

**ตัวอย่าง:** Satellite $45,000 · ทอง $4,200 · 1 lot = 100 oz (ตรวจสเปกโบรก)

| | Main ($31,500) | Tactical ($13,500) |
|---|---:|---:|
| Risk ต่อดีล | $630 | $270 |
| เพดานมูลค่า | $63,000 = 0.15 lot | $54,000 = 0.12 lot |
| Stop ที่ใช้ Risk เต็มได้ | ≥ $42 | ≥ $22.5 |
| Stop ปกติ | ตามโครงสร้าง Day | $20–30 → $20 ได้ Risk $240 · $25–30 ได้เต็ม $270 |

## 4. กติกา Main vs Tactical ตามสถานะ Bias

| Bias | Main | Tactical |
|---|---|---|
| **Neutral** | เข้าไม้กลับตัวได้ (Macro เริ่มเปลี่ยน + โครงสร้างกลับตัว) | ตาม Trend ที่ยังชัด ที่กรอบที่มีนัยยะ · สวนทิศ Main ได้ = Hedge |
| **Long / Short** | ตาม Bias | ตาม Bias เท่านั้น (เร่งกำไร) · ไม้สวนทิศที่ค้าง ออกตามกฎของตัวเอง · ห้ามเปิดไม้สวนใหม่ |

**Tactical มี 2 หน้าที่: เร่งกำไร + Hedge** · ตอน Neutral ทิศ "Trend เดิม" ดูจากโครงสร้าง High/Low บน Day (ไม่ใช้ EMA20 ที่แบนแล้ว)

| ช่วง Neutral | Tactical |
|---|---|
| มี Main · สวนทิศ Main (ตาม Trend เดิม) | ได้ = Hedge |
| มี Main · ทิศเดียวกับ Main | ไม่ได้ — รอ Bias เปลี่ยนเป็น Long/Short ก่อน (Trend ใหม่ยังไม่ยืนยัน) |
| ไม่มี Main | **ผู้ใช้ตัดสินเอง**: กรอบกว้าง → เทรดได้ · กรอบแคบ → หยุด · แอปไม่บล็อก แต่ติดป้าย `Range` ให้ไม้นี้ เพื่อแยกผลประเมินภายหลัง (ตัวช่วยจำ ไม่บังคับ: กรอบ ≥ 3 เท่าของ Stop Tactical เช่น ทอง ≥ $60–90) |

**Hedge (Tactical สวน Main ในสินค้าเดียวกัน · ตอน Neutral):**
1. เปิดได้เฉพาะเมื่อมีไม้ Main ค้าง
2. จำนวนสัญญา Hedge ≤ จำนวนสัญญา Main (สถานะสุทธิไม่พลิก)
3. นับ Risk ทั้งสองไม้เต็ม ไม่หักกัน (ราคาเหวี่ยงชน Stop ได้ทั้งคู่)
4. Main โดน Stop → Hedge ไม่ต้องปิดตาม · ออกตามกรอบ/Stop ของตัวเอง
5. ถือข้ามสุดสัปดาห์ได้ (ไม่ห้าม)

## 5. เพดาน Risk รวม
- **Satellite:** Open Risk รวม ≤ 1.2% ของพอร์ตรวม · แอปไม่มีราคา Sat สด → วัดจาก **Entry ถึง SL ปัจจุบัน** (เลื่อน SL เลย Entry แล้ว = 0)
- **สินค้าเดียวกัน:** Main + Tactical ≤ 0.6% ของพอร์ตรวม
- **Core:** นับเฉพาะ Risk ส่วนที่ขาดทุนจากทุน (Stop ต่ำกว่าทุน) · กำไรที่อาจคืนคุมด้วยเพดาน Drawdown 30% ของ Core
- **Core + Satellite:** ≤ **6%** ของพอร์ตรวม → งบ Core ≈ 4.8% (≈ 5 ตัวที่ Risk เต็มพร้อมกัน) · Core นับแบบ (ข) ตัวที่ Stop เลยทุนแล้วนับ 0 → เพดานนี้คุมเฉพาะความเสี่ยงที่ยังเสียจากทุนได้
- เหตุที่ไม่ใช้ 10%: หุ้น Core ส่วนใหญ่ไปทางเดียวกัน (Tech/Growth) วันตลาดลงแรงอาจชน Stop พร้อมกัน + Gap → เสียจริงได้ ~1.3–1.5 เท่าของ Open Risk · 10% → อาจเสีย 13–15% ของพอร์ตรวม เกินเบรก Core (20% ของ Core ≈ 14% ของพอร์ตรวม)
- สินค้า/ธีมเดียวกันข้ามพอร์ต นับร่วมกัน
- เบรก Drawdown เดิมของ Core: ลดขนาดที่ 12.5% · หยุดเปิดใหม่ที่ 20% ของพอร์ต Core
- **Max DD ของ Satellite ทั้งก้อน:** หยุดเปิดไม้ใหม่ที่ 20% (= 6% ของพอร์ตรวม · ปรับได้)
- **เบรก Tactical:** หยุดเปิดไม้ใหม่เมื่อเสียติดกัน **5 ไม้** หรือ Drawdown **10% ของ Tactical** (= 0.9% ของพอร์ตรวม · 5 ไม้ × Risk เต็ม 0.18% ก็เท่ากับ 0.9% พอดี) · Main ไม่หยุดตาม

## 6. ข้อควรเช็กกับโบรก
- S50 (Pi · TFEX): Long + Short สัญญาเดียวกันในบัญชีเดียวมักหักลบกัน → Hedge อาจต้องใช้คนละเดือน/คนละบัญชี
- XM / IC: เปิดสองฝั่งได้ แต่เสีย swap ทั้งสองฝั่ง

## 7. ประเมิน Tactical (ทุก 1–2 เดือน)
กำไรสุทธิหลังต้นทุน (spread/swap) · ผลต่อ Drawdown ของ Satellite · ช่วยให้ถือ Main ตามแผนได้ดีขึ้นไหม · ไม่มีโควตาต้องเทรดทุกสัปดาห์ (ไม่มี Setup = ถือเงินสด)

## Pine — Bias EMA20 State (ยังไม่ได้รันทดสอบ)
```pine
//@version=5
indicator("Bias EMA20 State", overlay=true)
len = input.int(20, "EMA")
n   = input.int(5,  "Slope bars")
k   = input.float(0.5, "Neutral if |slope| < k × ATR")
e   = ta.ema(close, len)
a   = ta.atr(14)
slope = e - e[n]
state = math.abs(slope) < k * a ? 0 : slope > 0 ? 1 : -1
plot(e, "EMA20", color = state == 1 ? color.green : state == -1 ? color.red : color.gray, linewidth = 2)
bgcolor(state == 0 ? color.new(color.gray, 88) : na, title = "Neutral")
```
