# TS1 — removed dead code (§3)

Method: every function / CSS selector / element id in `index.html` was counted against all of `index.html`, `*.js`, `tools/`, `scripts/`, `tests/` (inline `onclick=`, template strings, comments, property names and tests all count as users). Zero users = removed. Removal ran in repeated passes because removing one function can orphan another. Class / id names that the code builds at run time (`prefix-` + x, `c${n}`) were treated as used.

**Proof of no visible change:** 26 screens (Today · Flow · Watch · Plan · Journal · Port · New-plan popup · Core form · Watch full-screen · Settings expanded · second account, at 1440 and 390) were screenshotted on the original app and on this branch — byte-identical (one frame, Family Today 1440, differs between two runs of the *original* app too). Full regression before and after the removal: identical (34/41 ok, the same 7 failing suites).
