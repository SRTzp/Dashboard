## What changed (index.html)
- Left column of the Homework page = three tabs **Business | Results | AI thesis** (badge Lite / Deep / none). Default: Compounder → Business, Momentum → Results; remembered per stock (`localStorage dash.hw2Tab.<TICKER>`). Desktop ←/→ move between tabs (stop at the ends, not while typing, not with a popup open). Phone: `Business | Results | AI | Mine` (44px).
- **Business** = `facts.business[]`, 6 fixed boxes (Momentum 1, 2, 3, 6 in 2×2): number + question · rule flag label (ok green / watch amber / info grey, text from data) · answer · one line · source; `watch` boxes tinted; missing box → amber "Not disclosed". Under the boxes: `Not disclosed:` line and the *Latest results* strip with `Results ›`.
- **Results** = 2×2 tiles (question · answer + trend word · reason · 4 mini bars with values; negatives below a baseline) + compact rows + `More facts ▸`.
- **AI thesis** = header (mode · date · based on) + `Update ›`, summary rows, `s1–s4` fold-outs (first open, `[[terms]]` tappable), Lite upsell line; empty state with lite/deep chips for the track + `Import JSON ›`. Never fills the user's fields.
- Layout: columns 7 : 5, cards fill the viewport; page never scrolls at 1440×900; at 1280×800 the left card scrolls inside itself; right card keeps its footer (Save draft · Save · mark done · Copy for AI challenge) visible.
- Validator `ltFactsCheck` accepts the optional `q.ends`, `ask` (≤40), `business[]` (answer ≤120, line ≤140, flagText ≤22); bad pieces are dropped, never an error. Old JSON without them renders (box 1 from `biz` + `mix`, plus a hint line).
- Copy-for-AI text now includes the business boxes.
