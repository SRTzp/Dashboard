# HW1c · Import a Fact Sheet from the Homework page

## Built
- **Facts-only import** (`ltParse`): `living-thesis@1` with valid `facts` and no `sections` is a facts-only import. A full JSON takes the same path as before.
  - Stock with a thesis: only `thesis.facts` is replaced and new catalysts are appended (de-duplicated by date+event). One log line `facts updated (Q3 FY26)`. `summary`, `sections`, `kpi`, `tripwires`, `evidence`, history and hits are untouched.
  - Stock without a thesis: stores `{facts, summary:{biz}, catalysts, mode:'facts', date, asOf, basis}`. `wlThesisOf` returns null for it (new `wlThesisRaw` / `ltFactsOnly`), so every reader treats it as "no AI thesis yet": no Full thesis menu item, Compare hidden, no Today reminders, no "No sections".
  - Invalid `facts` in a facts-only JSON gives an error and nothing is saved. A file with neither sections nor facts still gives "No sections".
  - Result line in the import sheet: `Fact Sheet imported (Q3 FY26) · thesis unchanged`, with a Close button.
- **Homework page:** secondary `Import ›` in the Fact Sheet header (tooltip `Paste living-thesis JSON (facts or full)`). The fallback line is now `No Fact Sheet yet — run living-thesis facts TICKER, then Import ›`. Import opens `ltImportOpen(sym)` bound to the stock, and the page re-renders in place with the draft kept. Phone: same button in the Facts tab (44px).
- HW1 test strings updated for the new fallback line.
