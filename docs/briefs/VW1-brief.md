## 2. Sat — แท็บ แผน › Strategy สัปดาห์นี้
- ที่เก็บ: `satWeek/<สัปดาห์>` ของสินค้า ช่องใหม่ `chart: {url, at:'YYYY-MM-DD'}` · เขียนผ่าน `satwWrite` (ไม่ต้องเพิ่ม rule)
- มีกราฟ: แถบภาพ **สูงคงที่ 92px** (390 และ 1440 · `object-fit: cover`) ใต้หัวการ์ด เหนือแนวรับ/ต้าน · ป้ายมุมล่างซ้าย `W | D · <d MMM>` · ปุ่มมุมขวาบน `เปลี่ยน` (เปิดช่องวางลิงก์ + ปุ่ม `ลบกราฟ`)
- ไม่มีกราฟ: แถบเส้นประสูง 40px `＋ วางลิงก์กราฟ TradingView` → กดแล้วเป็นช่องกรอก + `บันทึก` / `ยกเลิก` (font ≥ 16px)
- สินค้าที่ซ่อน (BR1) ไม่แสดง · สินค้าที่เพิ่มเอง (AS1) มีแถบกราฟเหมือนกัน
- `satwCopyFromPrev`: คัดลอก `chart` ด้วย (ป้ายวันที่เป็นของเดิม — ให้เห็นว่ากราฟเก่า)

## 3. หุ้น — ที่เก็บ `users/{uid}/stockNotes/{SYM}`
- `SYM` = คีย์เดียวกับ `wlSymKey` (TH ไม่มี .BK ก็จับคู่ได้แบบ WL2)
- doc: `{event:[{id, d, t}], fund:[{id, d, t}], tech:[{id, d, t, chart?}], updated_at}` · `t` ≤ 140 ตัว · `d` = วันไทย · ใหม่อยู่หน้า · เก็บต่อมุม ≤ 50 รายการ (ตัดเก่าตอนเขียน)
- อ่านแบบ `onSnapshot` ทั้ง collection ครั้งเดียว (แบบ ideas/prices) · rule ยังไม่ตั้ง / อ่านไม่ได้ → แสดง `ยังอ่านโน้ตไม่ได้ (ต้องเพิ่ม Firestore rule stockNotes)` ในจุดโน้ต · ส่วนอื่นของแอปทำงานปกติ
- ไฟล์ rule ให้ผู้ใช้: `docs/firestore-rules-stockNotes.txt`
```
match /users/{uid}/stockNotes/{doc} {
  allow read, write: if request.auth != null && request.auth.uid == uid;
}
```
- ลบหุ้นออกจาก Watchlist → **ไม่ลบ** stockNotes

## 4. หุ้น — Watchlist card แท็บ "มุมมอง"
- เพิ่มแท็บ `มุมมอง` เป็นแท็บที่ 2 (ถัดจาก `สรุป`) · แถบแท็บที่ 390px ต้องไม่ล้นแนวนอนของหน้า (ถ้าเกินให้เลื่อนในแถบแท็บเอง)
- เนื้อแท็บ: 3 แถว `Event` · `Fund.` · `Tech` — แต่ละแถวบรรทัดเดียว: ป้ายมุม · ข้อความล่าสุด (`…`) · (Tech: ภาพย่อ 54×30 ถ้ามีกราฟ) · วันที่ · ไม่มีบันทึก = `— แตะเพื่อเพิ่ม`
- แตะแถว → มุมนั้นขยาย: ประวัติทั้งหมด (ใหม่ก่อน · Tech ที่มีกราฟแสดงภาพสูง 110px) + ช่องบันทึก (≤ 140 · ตัวนับ) · Tech มีช่องลิงก์กราฟ (ไม่บังคับ) · ปุ่ม `บันทึก` · แต่ละรายการลบได้ (ยืนยัน)
- ป้าย `สรุป` ของการ์ดไม่เปลี่ยน
