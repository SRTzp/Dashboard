## 1. แท็บ
- ปุ่มใหม่ `Today` **ซ้ายสุด** (`tabBtnToday` · `#tabToday` · key `today`) · หัวข้อในหน้ายังใช้ไทย ("ต้องทำ" ฯลฯ)

- คีย์ลัดตามตำแหน่งใหม่: `1` Today · `2` Flow · `3` Watch · `4` แผน · `5` Journal · `6` Port (`.kbdhint` แสดงเลขใหม่) · ปัดซ้าย/ขวาวนตามลำดับใหม่
- **เปิดแอป = แท็บวันนี้** (แทน Flow) · `switchTab('today')` เรียก `renderToday()`
- ปุ่มแท็บมีเลขแดง = จำนวนงาน 🔴 ด่วน (0 = ไม่แสดง) · อัปเดตทุกครั้งที่ render หลัก (เห็นได้จากทุกแท็บ)
- จอ ≤ 430px: 6 ปุ่มต้องอยู่บรรทัดเดียว ไม่ล้น (ลด padding/ตัวอักษร · ซ่อน `.kbdhint`)

## 2. หน้าตา (ตามม็อกอัป v1 · บนลงล่าง)
1. **หัว**: `ต้องทำ` + ชิป `n ด่วน` (แดง) · `n ภายในสัปดาห์` (เหลือง) · `n โอกาส` (ฟ้า) · ขวา: `{วันไทย d MMM} · ปิดสัปดาห์ {วันที่ราคาปิดล่าสุด}`
2. **Daily routine** (ข้อ 3)
3. **แถบสถานะเร็ว** (ชิปกดได้ → ไปหน้าที่เกี่ยว): ต่อบัญชีที่มีถัง · `DD Core x% · {สถานะ}` · `DD Sat x% · {สถานะ}` (สีตาม stage: ปกติเขียว · ลดขนาด/ฟื้นตัวเหลือง · พักแดง) · `heat Sat a / b%` · `ไม้ใหม่ Sat n / m` · `f {สถานะประตู}` · `ชั้น 2 Core a / b%` — ใช้ค่าจากฟังก์ชันเดิม (ห้ามคิดใหม่)
4. **กลุ่มงาน** 🔴 ด่วน · 🟡 ภายในสัปดาห์นี้ · 🔵 โอกาส · 🟢 ปกติ (ข้อ 4) — กลุ่มว่าง = ไม่แสดง · ไม่มีงานเลย = เหลือกลุ่มปกติ
- แถวงาน: ไอคอน · ข้อความหลัก (ticker ตัวหนา) · ป้ายช่วง Routine (`Plan TH` ฯลฯ) · บรรทัดรอง (ส่วน · บัญชี · ตัวเลขสั้น) · ปุ่มข้อความขวา (`ไปที่การ์ด →` ฯลฯ) · **กดทั้งแถว = ไปที่จุดนั้น** (ข้อ 5) · ขอบซ้ายสีตามกลุ่ม
- จอ ≤ 430px: ข้อความสั้นลง (ซ่อนบรรทัดรอง) · ปุ่มขวาเหลือ `→` · กลุ่มสัปดาห์นี้แสดง**ครบ** (ไม่ย่อ — ผู้ใช้เลือก v1)

## 3. Daily routine
- ค่าเริ่มต้น (จ.–ศ. · เวลาไทย):
  | id | เวลา | ชื่อ | ลิงก์ |
  |---|---|---|---|
  | planTH | 09:00–10:00 | Trading Plan TH | แท็บแผน → Core บัญชีที่ตลาด TH (Family) + การ์ด S50 |
  | selUS1 | 11:00–12:00 | Stock Selection #1 US | แท็บ Flow |
  | selUS2 | 13:00–14:00 | Stock Selection #2 US | แท็บ Flow |
  | planUS | 15:30–16:30 | Trading Plan US | แท็บแผน → Core บัญชีที่ตลาด US (main) + Sat |
  | selTH | 19:00–20:00 | Stock Selection TH | แท็บ Watch (กรองหุ้นไทย ถ้ามีตัวกรองตลาดอยู่แล้ว · ไม่มี = แค่เปิด Watch) |
- จอใหญ่: 5 ช่องเรียงแถวเดียว · มือถือ: เรียงลง (เวลา · ชื่อ · สถานะ)
- สถานะช่อง (เทียบเวลาไทยตอนนี้): ถึงเวลา = ฟ้า `●` + `เหลือ n นาที` · ติ๊กแล้ว = เขียว `✓` · เลยเวลาไม่ติ๊ก = เส้นประ `–` "ข้าม" · ยังไม่ถึง = เทา `○` · ช่องมีเลขแดง = จำนวนงาน (ทุกกลุ่ม) ที่ติดป้ายช่วงนั้นและยังไม่เสร็จ
- **ติ๊กเอง**: ปุ่มวงกลมในช่อง (กดชื่อช่อง = ไปลิงก์ · กดวงกลม = สลับติ๊ก) · ติ๊กย้อนช่องที่ "ข้าม" ได้ภายในวันเดียวกัน
- เสาร์–อาทิตย์: ไม่แสดง Routine (บรรทัดเล็ก "วันหยุด · Routine จ.–ศ.") · รายการงานแสดงปกติ
- **เช็กแผน Sat รายวัน** (งานตามรอบ · ผู้ใช้: ทุกตัว ทุกวัน อย่างน้อยวันละครั้ง): แถวเดียวในกลุ่ม 🟡 หัวกลุ่ม · `เช็กแผน Sat วันนี้` + ชิป 4 ตลาด `XAUUSD · BTC · S50 · Brent` ติ๊กทีละตัว (ติ๊ก = ชิปเขียว) · ครบ 4 = แถวหาย · กดชิป = ไปการ์ด Strategy ของตลาดนั้นในแท็บแผน · ป้ายช่วง: S50 → `Plan TH` · อีก 3 → `Plan US` · จ.–ศ. เท่านั้น
- **เก็บข้อมูล**: `state.settings.routine = {slots:[{id, start:'09:00', end:'10:00', name, link}], satDaily:['XAUUSD','BTC','S50','BRENT']}` (ไม่มี = ค่าเริ่มต้นข้างบน) · ติ๊กรายวัน `state.settings.routineLog = {'YYYY-MM-DD': {slots:[id…], sat:[asset…]}}` เก็บ 60 วันล่าสุด (ตัดเก่าตอนเขียน) · เขียนเฉพาะตอนกดติ๊ก (ใช้ทางบันทึก settings เดิม · รอ server ยืนยันแบบ `ddSync`)
- **ค่าตั้ง** (หน้าตั้งค่า หัวข้อใหม่ "Daily routine"): ตารางช่วง (เวลาเริ่ม · เวลาจบ · ชื่อ · ลิงก์ = select: แผน TH / แผน US / Flow / Watch / ไม่มี) · ปุ่ม ＋ เพิ่ม / × ลบ · ตรวจ: เวลา HH:MM · จบ > เริ่ม · ชื่อไม่ว่าง ≤ 30 ตัว · ช่วงไม่ทับกัน (ผิด = แดง + บันทึกปิด) · เรียงตามเวลาอัตโนมัติ · ช่อง ☐ 4 ตลาดของเช็กแผน Sat รายวัน · ปุ่ม "คืนค่าเริ่มต้น"
- ใต้ Routine บรรทัดเล็ก: `สัปดาห์นี้ทำครบ x/y ช่วง` (นับจาก routineLog จ.–วันนี้)
