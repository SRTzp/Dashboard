> ต่อจาก ST1 + WL4 · ผู้ใช้เลือก 6 ต.ค.: "ตัดชิปที่ซ้ำแผงดำ" (ตัวเลขหลักยังเห็นครบ) + รวมแก้ช่องวันข่าวที่ค้างจาก ST1
> สำรองก่อนแก้: `index.backup-pre-CX1.html` · `tests/_bk_cx1/` · ห้ามแตะ core-size.js · ห้ามเปลี่ยนสูตร/ตัวเลขใด ๆ (เปลี่ยนแค่การแสดง) · ห้ามย้อนงานรอบก่อน
> หลัก: ปกติ = เงียบ · ผิดปกติ = เห็นทันที

## 1. หัวบัญชีใน "Core · การ์ดตำแหน่ง" (`coreAcctHtml`)
ตอนนี้มี 9–10 ชิป ซึ่งหลายตัวซ้ำกับแผงสรุปสีเข้มด้านบน (`.sumBlk` ของ `acctActive`) → บนมือถือรกมาก

**บัญชีที่เป็น `acctActive` (แผงด้านบนแสดงบัญชีนี้อยู่แล้ว):**
| ชิป | แสดงบนหัวบัญชี |
|---|---|
| ป้ายตลาด (`ทั้งคู่`) · `ถัง Core` · DD (`ddChipHtml`) · `f` | แสดงเสมอ (ไม่ซ้ำแผง) |
| `จองเกินถัง` · คำเตือน Fund-flow (`ccFfWarn`) | แสดงเมื่อเกิด (เหมือนเดิม) |
| `เงินสดว่าง` · `ชั้น 2` · `L` · `บันไดใหม่` | **ปกติ = ย้ายเข้า `<details data-c-more>` ที่พับไว้** (หัวข้อ `รายละเอียด`) · **ผิดปกติ = แสดงบนหัวตามเดิม**: ชั้น 2 level `warn`/`over` · L เกินส่วน (`lv-over`) · บันไดใหม่ ไม่ต้องย้าย (สถานะ งด/เปิด อยู่ในแผงแล้ว → อยู่ใน details เสมอ) |
| `ขาดราคา` | แสดงเฉพาะเมื่อ > 0 (สี warn) · = 0 → อยู่ใน details |
| ราคาอัตโนมัติ (`pxStatusHtml`) | ปกติ = บรรทัดเล็กสีเทา 1 บรรทัดใต้แถวชิป (ไม่ใช่ชิป) · `err` / `stale` = ชิป warn ตามเดิม |
| `ขยายทั้งหมด · ยุบทั้งหมด` | แสดงเฉพาะเมื่อบัญชีมีการ์ด ≥ 1 ใบ |

**บัญชีอื่น (ไม่ใช่ `acctActive` · ตอนดูรวมหลายบัญชี):** ไม่มีแผงของบัญชีนั้น → แสดงชิปครบเหมือนเดิม ยกเว้น `ขาดราคา` = 0 ซ่อน (ใส่ใน details)

- `<details data-c-more>`: summary `รายละเอียด` (ตัวเล็ก ลิงก์สีเทา) · เปิดแล้วเห็นชิปที่ย้ายมา ครบทุกตัว · สถานะเปิด/ปิดไม่ต้องจำ
- **ทุก `data-c-*` เดิมต้องยังอยู่ใน DOM** (แค่ย้ายที่) · ตัวเลข/ข้อความในชิปเหมือนเดิมทุกตัวอักษร

## 2. ตัวเลขในชิป `.ccStat b`
- เลิกใช้ฟอนต์ mono (`var(--mono)`) → ฟอนต์เดียวกับตัวหนังสือ + `font-variant-numeric: tabular-nums` (ตัวเลขยังตรงคอลัมน์) · ใช้กับ `.ccStat` ทั้งแอป

## 3. ส่วน "วันข่าวสำคัญ (Sat)" ในตั้งค่า (`newsSetRender`)
- ช่องวันที่ · ประเภท · เวลา · ปุ่ม ใช้สไตล์เดียวกับช่องกรอกส่วนอื่นในหน้าตั้งค่า (ขนาด ความสูง มุมโค้ง สีพื้น เหมือน `.f input` ในส่วน "ความเสี่ยง SAT") · ตัวอักษรในช่อง ≥ 16px บนมือถือ (กัน iPhone ซูมเอง)
- แถววันข่าวที่บันทึกแล้ว: วันที่ + ประเภท ตัวหนังสือปกติ · ช่องเวลาสไตล์เดียวกัน · ปุ่ม × เป็นปุ่มรองขนาดแตะได้ ≥ 36px
- 390px: แถวใหม่ (วันที่ · ประเภท · เวลา · ＋ เพิ่ม) ไม่ล้นแนวนอน · ขึ้นบรรทัดใหม่ได้ (ปุ่มเพิ่มลงบรรทัดล่างเต็มกว้าง)
- ข้อความ `บันทึกแล้ว` หายเมื่อเริ่มพิมพ์แถวใหม่ (ไม่ค้าง)
