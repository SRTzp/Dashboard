# WL3-fix — คำศัพท์ที่มี `&` หรือ `'` ไม่กลายเป็นปุ่ม

> ตรวจ WL3 แล้ว (คลาวด์ 42 ชุดผ่าน · phase41 119/119) เจอบั๊ก 1 จุด
> สำรองก่อนแก้: `index.backup-pre-WL3fix.html` · `tests/_bk_wl3fix/run_tests_phase41.py` · ห้ามแตะ core-size.js

## บั๊ก
- `ltInl` แปลง `[[คำ]]` **หลัง escape แล้ว** → `t` เป็นข้อความที่ escape แล้ว (`R&amp;D`) แต่ตอนหาความหมายเรียก `ltTermKey(t…)` ซึ่ง `escHtml` ซ้ำอีกรอบ → ได้ `r&amp;amp;d` ไม่ตรงกับคีย์ใน `ltTermMap` (`r&amp;d`)
- ผล: `[[R&D]]` · `[[S&P 500]]` · `[[M&A]]` · `[[P&L]]` · `[[Moody's]]` แสดงเป็นข้อความเฉย ๆ ไม่ใช่ปุ่ม (แต่แถบคำศัพท์ยังแสดงคำนั้น) — คำการเงินแบบนี้เจอบ่อย

## แก้
- ใน `ltInl` ตอนหาความหมาย ใช้ `t` (ที่ escape แล้ว) ตัดแท็ก + ตัดช่องว่างหัวท้าย + ตัวเล็ก **โดยไม่ escape ซ้ำ** ให้ตรงกับรูปแบบคีย์ของ `ltTermsSet` (หรือเปลี่ยนทั้งสองฝั่งให้ใช้รูปแบบเดียวกัน — เลือกเองได้ แต่ต้องตรงกันทุกกรณี)
- `data-term` / ข้อความในปุ่ม / กล่องความหมาย ต้องแสดง `R&D` ถูกต้อง (ไม่เห็น `&amp;`)
- ไม่เปลี่ยนอย่างอื่น
