## 1. การ์ดแผน Sat: เงิน USD ติดเครื่องหมาย ฿
- `satV3PlanAdapter.sizeLine` (~12791): บัญชีที่โบรกใช้ USD (`c.chosen.cfg.cur==='USD'`) ตอนนี้แสดง `฿325` ทั้งที่เป็น USD
- ใหม่: บัญชี USD → `$325 · ≈฿11,050` (ตัวหลัก = USD ตามโบรก · ตัวเล็ก ≈ บาท จาก `c.base.riskTHB × factor`) · บัญชี THB → `฿x` เหมือนเดิม
- คูณ `factor` ทั้งสองตัวเหมือนเดิม · ป้าย "ลด x%" เหมือนเดิม · ซ่อนตัวเงิน (privacy) ต้องปิดได้ทั้ง `$` และ `฿`

## 2. BE / WIN ใช้เกณฑ์ปัดเดียวกันทุกที่
- ตอนนี้ไม้ +0.4: ป้าย = BE (ปัดเป็น 0 ใน `pnlTagHtml`) แต่สถิติ/ตัวกรองนับเป็น WIN (`realizedPnlOf(t)>0`)
- ใหม่: ฟังก์ชันเดียว เช่น `pnlOutcome(t)` → `'win'|'loss'|'be'` ใช้ค่าและการปัดเดียวกับป้าย → ใช้ใน: ป้าย · ตัวกรอง Journal win/loss (~8181) · `wins` ใน `statsFor` (~5908) · `wins` สถิติตาม setup (~8031)
- Win Rate = win ÷ ไม้ทั้งหมด (BE อยู่ในตัวหาร ไม่อยู่ในตัวตั้ง — เหมือนเดิม) · ตัวกรอง Win ไม่มีแถว BE

## 3. "฿-0"
- P&L ที่ปัดแล้วเป็น 0 (เช่น −0.3) ยังแสดง `฿-0` ใน: บล็อกสรุป Journal (~8147) · สถิติตาม setup (~8054) · ข้อความไม้นอกแผน / Setup ไม่ครบ (~8137, 8139) · สถิติ port (~8164)
- ใหม่: ใช้ `fmtPnl0` (มีอยู่แล้ว) ทุกจุดที่แสดง P&L เป็นจำนวนเต็ม → `฿0` · ไล่ grep `'฿'+fmt0(` / `฿${fmt0(` ที่เป็น P&L ให้ครบ (รายงานรายชื่อจุดที่แก้) · ป้ายกำไร/ขาดทุนข้างตัวเลข (pill) ต้องไม่ขึ้นเมื่อปัดแล้วเป็น 0

## 4. "0 ตัวรอสร้าง Thesis"
- แถบสถานะ Watchlist (~8757): `nNoCard === 0` → ไม่แสดงข้อความนี้ (ส่วนอื่นของแถบ เช่น error / ข้อมูลตัวอย่าง แสดงตามเดิม · ถ้าไม่เหลืออะไรเลย ไม่ต้องมีแถวว่าง)

## 5. "ตัวที่อ่อนสุด 0 ตัว" (sheet DD Core)
- (~5804) DD ≥ เกณฑ์ แต่ไม่มีตัวที่มีราคา → ตอนนี้ขึ้น "ตัวที่อ่อนสุด 0 ตัว … ไม่มีตัวที่มีราคา"
- ใหม่: หัวข้อ `ตัวที่อ่อนสุด — ยังเลือกไม่ได้` + บรรทัด `ไม่มีตัวที่มีราคาปิดสัปดาห์ — อัปเดตราคาก่อน` · มีตัวที่มีราคา → เหมือนเดิม

## 6. คำ "f" ตอนไม่มีไฟล์ Fund-flow
- (~6298) `⚠ ยังไม่มีข้อมูล Fund-flow · f 100%` → ผู้ใช้ไม่รู้ว่า f คืออะไร
- ใหม่: `⚠ ยังไม่มีข้อมูล Fund-flow · ไม่ลดขนาดไม้ (100%)` · (~6299) stale: `⚠ Fund-flow เก่า n วันทำการ · ไม่ลดขนาดไม้ (100%)` · จุดอื่นที่มีป้าย "Fund-flow f" อยู่แล้วไม่ต้องแก้

## 7. ตารางในการ์ด Thesis ที่ 390px ตัดตัวเลขกลางคำ
- ตาราง md (`ltMd` → `<table>`) ที่ 390px: "+127%" ขึ้นบรรทัดใหม่เป็น "+12 / 7%"
- ใหม่: ตัวเลข/คำในช่องตารางไม่ถูกตัดกลางคำ (เช่น `overflow-wrap:normal; word-break:keep-all` ในช่อง) · ตารางที่กว้างเกินให้เลื่อนแนวนอน **ภายในกล่องตาราง** (wrapper `overflow-x:auto`) · หน้าเว็บทั้งหน้าต้องไม่ล้นแนวนอน · จอใหญ่หน้าตาเหมือนเดิม
