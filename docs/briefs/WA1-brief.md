## ข้อตัดสิน
- **Strategy แสดงเฉพาะ Asset ที่เลือกสัปดาห์นี้** (`satWeekPickList(wk)` จาก MF1) · 1–3 ตัว · ไม่มีช่องคงที่ · สัปดาห์ใหม่เริ่มว่าง (ยกเว้นแผนที่ยกมาตาม CO1)
  - หัว: `สัปดาห์ 12–18 ต.ค.` + การ์ดเล็กต่อ Asset (ชื่อ + ป้าย Macro) + `＋ Asset` (มี 3 แล้วไม่มี) · แตะชื่อ = เลื่อนไปการ์ด · `⋯` = `เอาออกจากสัปดาห์นี้`
  - ว่าง: `ยังไม่ได้เลือก Asset สัปดาห์นี้ — เริ่มจาก Macro (แท็บ Flow) หรือ ＋ Asset`
- **`＋ Asset` (เจอ Chart สวย → เช็กกลับ Macro):** sheet ค้นหา (รายชื่อ Sat Asset ทั้งหมด: 4 ตัวเดิม + เพิ่มเอง · ช่องค้นหา) · แต่ละแถวมีป้าย Macro จาก `satPbKeyOf` (MF1): `▲ Macro ★` / `▲▬ Macro` / `▬ Macro Neutral` / `▼ Macro` / `นอก Macro` · ไม่เจอในรายการ → `＋ เพิ่มสินค้าใหม่` (AS1 sheet) · ทิศ ตาม/สวน ตัดสินตอนทำ Bias (ป้ายในรายการแสดงท่าทีอย่างเดียว)
- **เอาออก / สลับ** ได้ตลอด แม้มีแผนหรือไม้ค้าง → Asset นั้นไปแถบ `ไม้ค้าง · ไม่ได้เลือกสัปดาห์นี้ (n)` (พับได้ · จัดการไม้เดิมได้ครบ · **ห้ามเปิดไม้ใหม่ / Activate ใหม่** + เหตุผล `ไม่ได้เลือกสัปดาห์นี้ — เพิ่มกลับก่อน`) · ไม้ปิดหมด + แผนจบ → หายเอง
- ตัด checkbox `ซ่อน` สินค้า (BR1) ในตั้งค่า (ไม่ต้องใช้แล้ว · ค่าเดิมไม่ลบ ไม่อ่าน) · ชื่อที่แสดง / เพิ่ม / ลบสินค้าเพิ่มเอง คงเดิม
- **ตัวคูณขนาดไม้ตาม Macro (แทนกติกา SR1 "สวน Macro + Trend ×0.6")** — Trend ไม่อยู่ในกติกาแล้ว (ผู้ใช้เทรดตาม Trend อยู่แล้ว):
  | Macro เทียบทิศไม้ (`Calc.pbAlign`) | ตัวคูณ | ค่าเริ่ม |
  |---|---|---|
  | ตาม (`with`) | 1 | — |
  | Neutral (`neutral`) | **ปรับได้** | 1.0 |
  | สวน (`against`) | **ปรับได้** | 0.6 |
  | นอก Macro (`none` · ไม่มีใน Playbook) | ใช้ค่าเดียวกับ Neutral | — |
  - ตั้งค่า › Sat (ต่อบัญชี เหมือน RPT): `Macro Neutral × [1.0]` · `สวน Macro × [0.6]` · ช่วง 0.1–1.0 · ทศนิยม 2 ตำแหน่ง · ไม่ผ่าน = error + บันทึกไม่ได้
  - **สวน Macro / นอก Macro → ต้องกรอกเหตุผลสั้น ๆ** ในการ์ดแผน (`macro_note` ≤ 80 ตัว) ก่อนบันทึก order · ไม่กรอก = ปุ่มปิด + `เขียนเหตุผลที่เข้าสวน/นอก Macro`
  - ปุ่มเดิม `ใช้ไม้เต็ม (ไม่ตามกฎ)` คงไว้ (ไม้ติดป้าย `ไม่ตามกฎ` เหมือนเดิม) · ใช้กับทั้ง Neutral และ สวน
  - ค่าคงที่ `SAT_MACRO_CUT` เดิม → อ่านจากค่าตั้ง (ไม่ตั้ง = 0.6) · MR (ปิดอยู่) ใช้ค่า สวน Macro
  - ไม้ที่บันทึกแล้วเก็บ `macro_state` + `size_factor` ที่ใช้จริงเหมือนเดิม (ไม้เก่าไม่เปลี่ยน)
- **Today / งานรายสัปดาห์ (GL1 · TD2):** Bias นับเฉพาะ Asset ที่เลือกสัปดาห์นี้ · ไม่เลือกเลย → งาน `เลือก Asset สัปดาห์นี้ (เริ่มจาก Macro)` · Asset ในแถบไม้ค้างยังมีงานที่เกี่ยวกับไม้ (เติมไม้ · Stop) ตามเดิม
- ภาษา: คำทับศัพท์ใช้ English (Asset · Macro · Neutral)
