# PX2-fix — ลบการ์ดปิดแล้ว: ล้างธง "นอกแผน" ค้างของไม้ที่ผูกการ์ด · เทส 48 (เพิ่มเคส)

> ต่อจาก PX2 + ID3b · ตอบคำถามที่ CC หยุดถามใน PX2 ข้อ 3 · ผู้ใช้ตัดสิน 5 ต.ค.: **ล้างธงตอนลบการ์ด**
> เหตุผล: ไม้ที่ผูกการ์ด Core (`trade_id`) = ซื้อตามแผนจริง · ไม้เก่าบางตัวยังมี `unplanned:true` ค้างจากระบบเก่า (ตอนนี้ไม่นับเป็นนอกแผนเพราะมีการ์ดผูก — `tradeOffPlan`) · ลบการ์ดแล้วธงค้างจะทำให้กลายเป็นนอกแผนผิด ๆ
> สำรองก่อนแก้: `index.backup-pre-PX2fix.html` · `tests/_bk_px2fix/run_tests_phase48.py` · ห้ามแตะ core-size.js · แก้เฉพาะ `coreDeleteClosed` + ข้อความ sheet ยืนยัน

## แก้
- `coreDeleteClosed(id)`: ก่อนลบการ์ด หาไม้ที่ผูก (`trade_id` ของการ์ด · บัญชีเดียวกับการ์ด) → ถ้าไม้นั้นมี `unplanned === true` → ตั้ง `unplanned:false` ในไม้นั้นก่อน (ใช้ทางเขียนไม้เดิมของแอป · เขียนเฉพาะ field นี้ · ห้ามแตะ field อื่นของไม้) → แล้วค่อยลบการ์ด
- เขียนไม้ไม่สำเร็จ → **ไม่ลบการ์ด** + แสดง error (กันสถิติผิด)
- ไม้ไม่มีธง / ไม่พบไม้ (ถูกลบไปแล้ว — การ์ด "ลบไม้") → ลบการ์ดตามเดิม ไม่เขียนไม้
- sheet ยืนยัน: กรณีไม้มีธงค้าง เพิ่ม 1 บรรทัด `ไม้นี้ติดธง "นอกแผน" ค้างจากระบบเก่า — จะตั้งเป็น "ตามแผน" ให้ (ซื้อผ่านการ์ด)`

## เทส — เพิ่มเคสท้าย `tests/run_tests_phase48.py` (เคสเดิมห้ามแก้ · จำนวนเคสเพิ่มขึ้น)
8. การ์ดปิดแล้ว + ไม้ผูกที่ `unplanned:true` → sheet มีบรรทัดธงค้าง · ลบ → ไม้ `unplanned:false` (field อื่นของไม้เท่าเดิมทุกตัว) · การ์ดหาย · จำนวนไม้นอกแผน / `statsFor` / สถิติ setup เท่าก่อนลบ
9. ไม้ไม่มีธง → ไม่มีบรรทัดธงค้าง · ลบแล้วไม้ไม่ถูกเขียน (เทียบ doc ก่อน/หลัง) · การ์ด "ลบไม้" (ไม่มีไม้) → ลบได้ ไม่ error
10. จำลองเขียนไม้ล้ม → การ์ดยังอยู่ + error บนจอ
