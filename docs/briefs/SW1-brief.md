## ข้อตัดสิน
- หน้า Strategy (Sat) มี **ช่องเฝ้าดู เริ่ม 2 ช่อง · กด `＋` เพิ่มเป็น 3 ได้ (สูงสุด 3)** · แต่ละช่องเลือก Asset ได้จากรายการทั้งหมด (4 ตัวเดิม + ตัวที่เพิ่มเอง AS1) · ห้ามซ้ำกัน · เอาออกเหลือ 1 ได้ (ต่ำสุด 1)
- **สลับได้ตลอด** แม้ตัวเดิมมีแผนหรือไม้ค้าง → ตัวเดิมย้ายไปแถบ `ไม้ค้าง · ไม่ได้เฝ้า` (แสดงแผน/ไม้เดิมครบ จัดการได้ตามปกติ: ปิดไม้ · เลื่อน SL · ยกเลิกแผน) **แต่ห้ามเปิดไม้ใหม่** (บันทึก order ใหม่ / Activate เงื่อนไขใหม่ ถูกบล็อก + เหตุผล `ไม่ได้เฝ้าดูแล้ว — เพิ่มกลับเข้าช่องก่อน`) · ไม้ที่ปิดหมด + แผนจบ → หายจากแถบเอง
- **Macro Playbook แยกอิสระ:** Playbook ทั้ง 4 (XAUUSD · BTC · BRENT · US) ในแท็บ Flow ยังอยู่ครบเสมอ ไม่ขึ้นกับว่าเฝ้าดู Asset ไหน
- **Link Asset ตั้งที่การ์ด Playbook (แท็บ Flow):** บรรทัด `Link Asset: XAUUSD · XAG ＋` · แตะ ＋ = เลือก Asset (รายการทั้งหมด 4 ตัวเดิม + เพิ่มเอง) · แตะชิป = เอาออก · **1 Asset ผูกได้ 1 Playbook** (เลือก Asset ที่ผูก Playbook อื่นอยู่ → ย้ายมาที่นี่ + ข้อความเล็ก `ย้าย XAG จาก BTC`) · ค่าเริ่ม: XAUUSD→XAUUSD · BTCUSD→BTC · BRENT→BRENT · S50 และตัวเพิ่มเอง = ไม่ผูก
- ผลของ Link ใช้กับทุกที่ที่ตอนนี้อ่าน `SAT_PB_ASSET` / `IDEA_ASSET_PB` (Macro stance ในการ์ด Sat · F2c ขนาดไม้ ×0.6 สวน Macro+Trend · ลิงก์จากการ์ด Sat ไปแท็บ Flow)
- การซ่อนสินค้าเดิม (BR1 `satAssetCfg.hidden`) → **แทนด้วย "ไม่ได้อยู่ในช่องเฝ้าดู"** (ค่าเดิมที่ hidden:true = ไม่อยู่ในช่องตอน migrate) · ชื่อที่แสดง (label) ของ BR1 คงไว้

## 1. ที่เก็บ (settings ของ `acctList[0]` เหมือน AS1/BR1 · ไม่ต้องเพิ่ม rule)
- `satWatch: ['XAUUSD','BTCUSD']` (ลำดับ = ลำดับช่อง · 1–3 ตัว · key ต้องมีอยู่ใน `satAssets({all:true})`)
- `satPbLink: {XAG:'XAUUSD', NVDA:'US', XAUUSD:'none', …}` (asset → playbook · เก็บเฉพาะที่ต่างจากค่าเริ่ม · `'none'` = ไม่ผูก · แก้จากการ์ด Playbook ในแท็บ Flow)
- **ไม่มี `satWatch` (ผู้ใช้เดิม)** → อ่านเป็น: ตัวที่ไม่ hidden ตามลำดับ `satAssets()` เดิม ตัด **2 ตัวแรก** (ไม่เขียนกลับตอนอ่าน · เขียนเมื่อผู้ใช้กดบันทึกช่อง) · ตัวที่เหลือที่มีแผน/ไม้ → แถบไม้ค้าง
- ฟังก์ชันกลาง: `satWatchList()` (keys ที่เฝ้า) · `satIsWatched(key)` · `satPbAssetOf(key)` (คืน 'XAUUSD'|'BTC'|'BRENT'|'US'|null) — **แทนการอ่าน `SAT_PB_ASSET[...]` / `IDEA_ASSET_PB[...]` ตรง ๆ ทุกจุด** · `satAssets()` (ไม่ใส่ all) = เฉพาะที่เฝ้า ตามลำดับช่อง

## 2. หน้าตา
- หัวหน้า Strategy: แถบช่อง `[XAUUSD ▾] [BTC ▾] [＋]` (มี 3 แล้วไม่มี `＋`) · แตะช่อง → เมนูเลือก Asset (รายการทั้งหมดที่ยังไม่อยู่ในช่องอื่น + `เอาออก` · เหลือ 1 ช่องแล้วเอาออกไม่ได้) · **การ์ด Asset แสดงแค่ตัวที่อยู่ในช่อง (2–3 การ์ด)** · ไม่มีตั้ง Macro ในเมนูนี้
- การ์ด Asset: บรรทัด Macro เดิม แสดง Playbook ที่ผูก เช่น `Macro (XAUUSD): Bullish v002` + แตะ = ไปแท็บ Flow การ์ด Playbook นั้น · ไม่ผูก = `Macro: — · ตั้ง Link ที่แท็บ Flow` จาง (แตะ = ไปแท็บ Flow)
- แท็บ Flow การ์ด Playbook ทั้ง 4: บรรทัด `Link Asset:` + ชิป Asset + `＋` (ตามข้อตัดสิน) · ชิปของ Asset ที่อยู่ในช่องเฝ้าดูมีจุดเล็ก
- แถบ `ไม้ค้าง · ไม่ได้เฝ้า (n)` ใต้ช่องทั้งหมด (พับได้ · ไม่มี = ไม่แสดง)
- Today / งาน Bias รายสัปดาห์ (GL1 · TD2 เช็กแผน Sat) นับ **เฉพาะ Asset ที่เฝ้า** (ตัวที่ไม่ได้เฝ้าไม่ต้องทำ Bias) · ไม้ค้างของตัวที่ไม่ได้เฝ้ายังขึ้นงานที่เกี่ยวกับไม้ (เช่น เติมไม้ได้ / Stop) ตามเดิม
- ตั้งค่า › สินค้า Sat (BR1/AS1): ตัด checkbox `ซ่อน` ออก (ใช้ช่องเฝ้าดูแทน) · ชื่อที่แสดง / เพิ่มสินค้า / ลบสินค้าเพิ่มเอง คงเดิม · ลบสินค้าที่อยู่ในช่อง → เอาออกจากช่องด้วย
- ภาษา: คำทับศัพท์ใช้ English (Asset · Macro · Playbook)
