## ข้อตัดสิน
- ที่อยู่: **Watch › Ideas** (หน้าเดิม) + ตัวกรองประเภท `ทั้งหมด · เทรด n · ลงทุน n` (ไอเดียเดิม idea@1 = ลงทุน) · ตัวกรองสถานะเดิม (`[ ]`) ยังใช้ได้
- **ก่อน `＋ วางแผน` ต้องมีฝั่งเรา: ทิศ + ผิดเมื่อ** (อย่างน้อย 1 ข้อ) · ไม่ครบ → ปุ่มปิด + `เขียนทิศ และ "ผิดเมื่อ" ของเราก่อน`
- AI ใช้ 2 แบบ (skill idea-scout โหมดใหม่ ทำแยก — รอบนี้ทำฝั่งแอปรับ JSON):
  1. **เสนอ** รายสัปดาห์ 0–3 ไอเดีย (`trade-batch@1`) → เข้าเป็นสถานะ `ร่าง` มีแต่ฝั่ง AI
  2. **ตรวจ** ไอเดียของเรา (`trade@1` id เดียวกัน) → เติมฝั่ง AI ข้างของเรา
- Macro Playbook ไม่เปลี่ยนตามไอเดีย · ไอเดียแค่แสดงป้าย ตาม / Neutral / สวน / นอก Macro

## 1. ที่เก็บ
- Firestore เดิม `users/{uid}/ideas/{id}` (rules เดิมครอบอยู่แล้ว — ตรวจ) · field ใหม่ `kind: 'trade'` (ไม่มี = ไอเดียลงทุนเดิม · อ่านเหมือนเดิมทุกจุด)
- ไอเดียเทรด:
  - `ai` = JSON `trade@1` ล่าสุดจาก AI (ไม่รวม log) · Import ใหม่ **แทนที่ `ai` เท่านั้น**
  - `me` = ฝั่งเรา `{dir:'long'|'short', strength:'low'|'mid'|'high', horizon, counter:[], wrong_if:[], alts:[], one_line, chain:[], asset_hint, tf}` · **ไม่มีอะไรเขียนทับ `me` นอกจากผู้ใช้** (ปุ่ม `ใช้ข้อของ AI` = คัดลอกค่าแถวนั้นเข้า `me` ทีละแถว)
  - `user` = `{status, product, ack:{row:true}, sat_key, week, expires, updated_at}`
  - `idea_log` append เหมือนเดิม
- สถานะ: `ร่าง` · `เฝ้า` · `ในแผน` (มี pick สัปดาห์นี้) · `พัก` · `หมดอายุ` · ลบ = กติกา ID1 เดิม

### Schema `trade@1` (เขียนลง `docs/trade-idea-schema.md` พร้อมตัวอย่าง)
```json
{"schema":"trade@1","id":"cxmt-kospi-2026-10","title":"CXMT กดราคา Memory → KOSPI ▼",
 "date":"2026-10-15","expires":"2026-10-29","asset_hint":"KOSPI200","dir":"short","tf":"D","horizon":"1–2 สัปดาห์",
 "one_line":"…","chain":[{"step":"CXMT ขยาย DDR5/HBM","note":"ตัวจุดชนวน"}],
 "strength":"mid","counter":["…"],"wrong_if":["…"],"alts":["…"],
 "products":[{"name":"KOSPI200 Futures","type":"futures","lev":"สูง"},{"name":"Inverse 2X ETF","type":"etf_lev","lev":"2X รายวัน"}],
 "entry":"Break ใต้แนวรับ D + Vol","sources":[{"title":"…","url":"https://…","date":"2026-10-14"}]}
```
- `trade-batch@1` = `{"schema":"trade-batch@1","date":"…","ideas":[trade@1 …]}` (0–3 ตัว)
- ตรวจ: id `[a-z0-9-]` ≤ 60 · dir long|short · tf 4H|D|W · expires ≥ date · `one_line` ≤ 120 · ช่องผิด = error ชัดเจน (เหมือน idea@1)

## 2. หน้าตา (ตามม็อกอัป)
- **รายการ** (①): แถว = จุด · ชื่อ · `[เทรด]` ทิศ · ระยะ · ใครใส่ (`AI` / `เรา` / `AI + เรา`) · ขวา: ป้าย Macro + `หมดอายุ dd MMM` หรือ `✓ สัปดาห์นี้`
  - จุด: เขียว = ในแผนสัปดาห์นี้ · เหลือง = มีงาน (ฝั่งเรายังว่าง / มีแถว `ขาด` ที่ยังไม่รับทราบ / หมดอายุใน ≤ 3 วัน / หมดอายุแล้ว) · เทา = เฝ้ารอ
- **การ์ด** (②–⑤) 4 แท็บ: `สรุป` · `AI vs เรา` (badge = จำนวนแถว ต่าง+ขาด ที่ยังไม่รับทราบ) · `Product` · `เข้า/ยกเลิก` · คีย์ ← → / ↑ ↓ / Esc มือถือ ใช้กลไก Ideas เดิม
  - สรุป: หนึ่งบรรทัด · ห่วงโซ่ (เส้นแนวตั้ง จุดท้ายสีตามทิศ) · ที่มา (ลิงก์ · วันที่ · ผู้ใส่) · ปุ่ม `＋ วางแผน` `ขอ AI มอง` `⋯`
  - AI vs เรา: ตาราง 3 คอลัมน์ แถว ทิศ · ความแรง · ระยะ · ข้อโต้แย้ง · ผิดเมื่อ · ทางเลือก
    - `ต่าง` (แดงอ่อน) = ทิศ หรือ ความแรง ไม่ตรงกัน · `ขาด` (เหลือง) = AI มีแต่เราว่าง (ข้อโต้แย้ง/ผิดเมื่อ/ทางเลือก)
    - ต่อแถว: `ใช้ข้อของ AI` · `เขียนของเรา` · `รับทราบ` (ซ่อนป้าย ไม่นับ badge)
    - ไม่มีฝั่ง AI → คอลัมน์ AI = `— ยังไม่ได้ขอ AI มอง`
  - Product: รายการจาก `ai.products` + เพิ่มเอง · เลือก 1 ตัว (`user.product`) · type `etf_lev` → กล่องเตือน decay (ข้อความตามม็อกอัป) · type `option` → ป้าย `→ Port Option` (ยังไม่เชื่อม แค่ป้าย)
  - เข้า/ยกเลิก: เข้าเมื่อ · ยกเลิกเมื่อ (= wrong_if ของเรา ถ้าว่างใช้ของ AI + ป้าย AI) · หมดอายุ (แก้วันได้ · `ต่ออายุ 1 สัปดาห์`)
- **`＋ ไอเดีย`** (⑦): ข่าว/ลิงก์ · ห่วงโซ่สั้น (ข้อความเดียว แยกด้วย `→` เป็น chain) · ทิศ (seg Long แดง/เขียวตามทิศ) · TF 4H|D|W · ตัวที่จะเทรด · หมดอายุเริ่ม = วันนี้ + 14 วัน · ปุ่ม `บันทึก` / `บันทึก + คัดลอก prompt ให้ AI`
- **`ขอ AI มอง`** = คัดลอก prompt (ข้อมูลฝั่งเรา + คำสั่ง `ใช้ idea-scout โหมด trade-check ตอบ JSON trade@1 id: <id>`) · Import JSON ที่ปุ่ม 📥 เดิมของ Ideas (แยก schema อัตโนมัติ: idea@1 / trade@1 / trade-batch@1)

## 3. `＋ วางแผน` → Strategy สัปดาห์นี้ (⑥)
- หา Sat key: `user.product` → ถ้าตรง Sat Asset ที่มี (หรือ `asset_hint` ตรง) → `satWeekPickAdd(key)` · ไม่มี → เปิด sheet เพิ่มสินค้า (AS1) เติม key/label ให้ แล้วเพิ่มเข้าสัปดาห์ · ครบ 3 → ข้อความเดิมของ MF1
- ป้าย Macro: `satPbKeyOf(key)` + ทิศ `me.dir` → `Calc.pbAlign` → ตาม / Neutral / สวน / นอก Macro (ใช้ตัวคูณ WA1 เดิม ไม่เพิ่มกติกาใหม่)
- แผนที่สร้างจากไอเดียเก็บ `idea_id` · การ์ดแผนแสดงลิงก์ `💡 ไอเดียต้นเรื่อง` (แตะ = ไปการ์ดไอเดีย) · สวน/นอก Macro → `macro_note` เติมจาก `one_line` ตัดเหลือ ≤ 80 ตัว (แก้ได้)
- ไอเดีย → สถานะ `ในแผน` · ปุ่มเป็น `✓ สัปดาห์นี้`
