## 1. Strategy สัปดาห์นี้ (การ์ดต่อสินทรัพย์ · กล่องมืดเดิม)
เรียงในการ์ด:
1. ชื่อสินทรัพย์ + ปุ่ม `+ แผน`
2. **รูปกราฟแบบเดิม** (ใช้ของเดิม + กติกา RR2 ไม่โหลดซ้ำ) · มุมขวาบนของรูปมีปุ่ม `เปิด TradingView ↗` (ลิงก์กราฟที่ผู้ใช้ตั้งไว้ · ไม่มีลิงก์ = ไม่แสดงปุ่ม)
3. **Trend**: ปุ่ม `▲ Up` / `▼ Down` + ช่องติ๊ก `Flat` (ตาม Pine Bias EMA20) — **แทนปุ่ม Bias เดิม** โดยแปลงเก็บลงช่อง bias เดิม:
   - Up = `Long` · Down = `Short` · ติ๊ก Flat = `Neutral` (เก็บทิศเดิมเพิ่มที่ `trend_dir: 'up'|'down'` เพื่อให้รู้ว่า Flat มาจาก Trend ไหน)
   - ลิงก์เล็ก `งดเทรดสัปดาห์นี้` ใต้แถว Trend = `None` เดิม (การ์ดจาง · ไม่มี + แผน)
   - ข้อมูลเก่าที่ bias = Neutral แต่ไม่มี trend_dir → แสดง Flat ติ๊ก ไม่เลือกทิศ
4. แถวละเรื่อง (ป้ายซ้าย ค่าขวา): `Macro` (สรุปบรรทัดเดียว) · `รับ / ต้าน` · `Trend Shift`
5. พับ: `เหตุผล · Driver · องค์ประกอบ` (ของเดิมทั้งหมด แก้ได้ครบเหมือนเดิม)
6. ไม้ค้าง/แถบ Risk รวมของสินทรัพย์ (PV2b) คงไว้ใต้การ์ด
- หัวกล่อง: บรรทัดบัญชีเดิม (ย่อได้) + แถบ Risk Satellite (PV2b) — ไม่เพิ่มอะไร

## 2. ฟอร์มแผน (การ์ดขาว · ต่อเนื่องหน้าเดียว ไม่มีแท็บ)
เรียงจากบนลงล่าง:
1. หัว: `XAUUSD · แผนใหม่` + สถานะเดิม
2. `ส่วน` : `Main | Tactical` (เดิม)
3. `ทิศ` : `▲ Long | ▼ Short` — **ค่าเริ่มตาม Trend** (Up→Long · Down→Short · Flat → ตามกติกา PV2b เดิม: มี Main ค้าง = ทิศตรงข้าม ไม่มี = ตาม trend_dir) · กดเปลี่ยนได้ · ถ้าสวนแล้วกติกาเดิมบล็อก → แสดงเหตุผลบล็อกเดิม (ไม่เปลี่ยนกฎ)
4. `Setup` : **ปุ่มชิป** (ไม่เลือก = ขาวขอบเทา · เลือก = พื้นดำ + `✓ ชื่อ`) ตามรูปที่ผู้ใช้ส่ง · รายการตามส่วน:
   - **ค่าเริ่ม Main: `Break EMA20` · `Break PoC Week`** · **Tactical: `Break EMA50` · `PoC Support`** (เปลี่ยนค่าเริ่มใน SAT_V2_DEF · ผู้ใช้ที่ตั้งเองไว้แล้วไม่ทับ)
5. `เสริม` : ช่องข้อความเดิม (≤ 60 ตัว)
6. `Entry · SL · TP` **แถวเดียว 3 ช่อง** (TP Tactical = คิดให้ แสดงเป็นข้อความแทนช่อง)
7. **ขนาดไม้ทุกบัญชีเรียงต่อกัน** (บัญชีหลัก · Family) — แถวละบัญชี: ชื่อ+โบรก · lot · Risk$ · ✓/⚠ · บรรทัดเล็ก `ไม้ 1 จาก 3 (50/30/20)` · ตารางเพดาน/ตัวจำกัดพับไว้ `รายละเอียด ▸`
8. ข้อความบล็อก/เตือน: รวมในกล่องเดียวใต้ขนาดไม้ (ข้อความเดิม ไม่ตัดข้อไหน)
9. ปุ่ม `บันทึก order ทุกบัญชีที่พร้อม (n)` (เดิม)
- ซ่อนจากฟอร์ม Lean: TF (ใช้ค่าเริ่มของส่วน · แก้ได้ใน `รายละเอียด ▸`) · บล็อก Macro/Driver ยาว (เหลือบรรทัด `Macro: … · ขนาดไม้ เต็ม/ลด x%`) · เหตุผลสวน Macro ยังโผล่เมื่อกฎเดิมบังคับ
- แผนรูปแบบเดิม (bp) ในโหมด Lean: แสดงพับเป็นแถว `รูปแบบเดิม · n แผน` ท้ายรายการ กดกางแล้วเป็นการ์ดเดิม
