## 0. ทำไม
- ไอเดียตั้ง "พร้อมส่งต่อ" ไม่ได้ถ้ามีข้อที่ขาดระดับ "ต้องรู้" เปิดอยู่ (กติกาข้อ 4 ของ `ideaReady`) — ตอนนี้ปิดได้ทางเดียวคือรัน AI ใหม่ทั้งรอบ · รอบนี้ให้ผู้ใช้ส่งสิ่งที่หามาเอง หรือปิดเป็น "หาไม่ได้" ในแอป

## 1. ตารางข้อที่ขาด (แท็บ หลักฐาน · `ideaTabEvd`)
- เรียง: ต้องรู้ → ติดตาม · ระดับ `skip` (ข้าม) ย้ายไปแถบพับ `ข้าม (n)` ท้ายตาราง (ไม่ลบ)
- แถวสถานะ `open`: ช่องติ๊กเลือก + ปุ่ม `📝 ตอบ` + ปุ่ม `หาไม่ได้`
- แถว `answered`: แสดงคำตอบ + แหล่ง (`answer_src`) + วันที่ · ไม่มีปุ่ม
- แถว `unanswerable`: แสดงเหตุผล + ใช้อะไรแทน · ถ้าผู้ใช้ปิดเองในแอป → ปุ่ม `เปิดใหม่`
- ติ๊กหลายข้อ → ปุ่มเหนือตาราง `📝 ตอบที่เลือก ({n})` (ไม่ติ๊ก = กดไม่ได้)
- มือถือ 390: ตารางเป็นรายการซ้อนแบบเดิม (WL2) · ปุ่มกดได้ ≥ 36px · ไม่ล้นแนวนอน

## 2. 📝 ตอบ (sheet · ไม่เรียก AI)
- 1 กล่องต่อข้อที่เลือก: `#{id} {q}` + `หาจาก: {where}` (ตัวเล็ก) + ช่องข้อความ `สิ่งที่หามา (ข้อความ / ลิงก์)`
- บรรทัดบอก: `ภาพหน้าจอ / PDF → แนบในแชท AI พร้อมคำสั่งนี้`
- ร่างข้อความที่พิมพ์ จำไว้ต่อ ไอเดีย+ข้อ (localStorage · try/catch) — ปิด sheet แล้วเปิดใหม่ยังอยู่ · คัดลอกแล้วไม่ล้าง (ล้างเมื่อ Import แล้วข้อนั้นไม่ใช่ open)
- ปุ่ม `คัดลอกคำสั่ง` (ทุกช่องว่าง = กดไม่ได้ + เหตุผล):
```
idea-scout update · ตอบข้อที่ขาด #{id}, #{id}
ไอเดีย: {name} ({id})
#{id} {q}
สิ่งที่ผู้ใช้หามา: {ข้อความ}
#{id} …
(ภาพ / PDF แนบในแชทนี้ ถ้ามี)
---
JSON เดิม (idea@1):
{ผล Export เดียวกับปุ่ม Export JSON}
```
- ข้อที่ช่องว่างแต่ถูกติ๊ก → ตัดออกจากคำสั่ง (ไม่ส่งข้อว่าง)
- ข้อความยืนยัน `คัดลอกแล้ว — วางให้ idea-scout แล้ว 📥 Import ผลกลับมา`

## 3. ปิดเป็น "หาไม่ได้" ในแอป (ไม่ใช้ AI)
- sheet: `#{id} {q}` + ช่อง `เหตุผล*` (เช่น บริษัทไม่เปิดเผย) + ช่อง `ใช้อะไรแทน` + ติ๊ก `ยอมรับความเสี่ยงโดยไม่มีตัวแทน` → บันทึกได้เมื่อมีเหตุผล **และ** (ใช้อะไรแทน ไม่ว่าง **หรือ** ติ๊กยอมรับ)
- เก็บใน `user.gaps[{id}] = {status:'unanswerable', reason, proxy, accept_risk, at}` (ค่าของผู้ใช้ · Import ใหม่ไม่ทับ — แบบเดียวกับ status/pick/cand)
- `ideaView` รวมผล: ข้อที่ `idea` ยัง `open` + มี `user.gaps` → แสดงเป็น หาไม่ได้ (ผู้ใช้) · ถ้า `idea` (ผล AI ใหม่) เป็น `answered`/`unanswerable` แล้ว → ใช้ของ `idea` (ค่าผู้ใช้เก็บไว้ ไม่ลบ แต่ไม่แสดง)
- `ideaReady` ใช้สถานะที่รวมแล้ว → ปิด "ต้องรู้" ด้วยหาไม่ได้ = ผ่านข้อ 4
- `เปิดใหม่` → ลบ `user.gaps[{id}]` (ยืนยันในตัว sheet)
- Export JSON (`ideaExportObj`): ข้อที่ผู้ใช้ปิดเอง → `status:"unanswerable"` · `answer:"หาไม่ได้: {reason} · ใช้แทน: {proxy | ยอมรับความเสี่ยง}"` · `answer_src:"ผู้ใช้"` · `answered_at:{วันที่}` (ให้ skill เห็นตอนรันรอบถัดไป)

## 4. Import ผล update
- ตัวอย่างก่อนบันทึก (diff เดิมของ ID1) เปลี่ยนบรรทัด `ข้อที่ขาดที่ปิด: n ข้อ` เป็นรายชื่อ `ข้อที่ขาดที่ปิด: #1 ตอบแล้ว · #3 หาไม่ได้` · ข้อที่ยังเปิด n ข้อ
- หลังบันทึก: ร่างข้อความของข้อที่ไม่ใช่ open แล้วถูกล้างจาก localStorage
- ป้าย `U` ในตารางหลักฐานต้องแสดงได้ (ถ้า `ltTag` ยังไม่รู้จัก U → แสดง `(ผู้ใช้)` สีเทาแบบป้ายอื่น · ใส่คำอธิบายในแถบคำศัพท์)
