## 1. คำศัพท์ `[[keyword]]` (แตะ/ชี้ดูความหมาย)
- `ltInl` (ใช้ทั้งใน md และ summary/kpi/gaps/tripwire/catalyst): หลัง escape แล้ว แปลง `[[คำ]]` (1–40 ตัวอักษร ไม่มี `[` `]` ข้างใน) เป็น `<button type="button" class="ltTerm" data-term="คำ">คำ</button>`
  - ความหมายหาจาก `thesis.terms[]` ของการ์ดที่กำลังแสดง (เทียบ `k` แบบไม่สนตัวพิมพ์ · ตัดช่องว่างหัวท้าย) → ใส่ `title` = ความหมาย
  - ไม่เจอใน terms → แสดงคำเฉย ๆ (ไม่มีเส้นใต้ · ไม่ใช่ปุ่ม · ไม่มี `[[ ]]` หลุด)
  - หน้าตา: ตัวอักษรเดิม + เส้นใต้ประสีเทา (`text-decoration: underline dotted`) · ไม่มีกรอบ/พื้น · ไม่เปลี่ยนขนาดบรรทัด
- กดคำ (คลิก/แตะ/Enter) → กล่องเล็กลอยใต้คำ: **คำ** (ตัวหนา) + ความหมาย 1–2 บรรทัด · กดที่อื่น / Esc / เลื่อนหน้า / กดคำเดิมซ้ำ = ปิด · มีได้กล่องเดียว · ต้องอยู่ในจอ (ชิดขอบซ้าย/ขวาเมื่อใกล้ขอบ · 390px ไม่ล้น) · จอใหญ่ hover = `title` ปกติก็พอ
- `terms[]` ใน Import (`ltParse`): ไม่มี/ไม่ใช่ array = `[]` · เก็บเฉพาะ `{k: string ไม่ว่าง ≤40, th: string ≤200}` · ตัดซ้ำ (k เดียวกัน เก็บตัวแรก) · ≤ 50 รายการ
- **ป้ายความน่าเชื่อในเนื้อหา (ผู้ใช้ 3 ต.ค.):** skill ใหม่เขียน `(Mgmt)` `(Inference)` `(Assumption)` `(Unknown — …)` ในวงเล็บแทน [M][I][A][?] (อาจมีข้อความต่อ เช่น `(Mgmt · งบยังพิสูจน์ไม่ได้)`) → แสดงเป็นตัวอักษรตามเดิม แต่คำ `Mgmt` / `Inference` / `Assumption` / `Unknown` ที่อยู่ติดหลัง `(` ทำเป็นสีเทาเล็กน้อย (ไม่ต้องเป็นปุ่ม) · ป้ายแบบเก่า `[F]` ฯลฯ ใน thesis เก่ายังเป็น chip เหมือนเดิม
- **แถบพับ "คำศัพท์ · n คำ" (ใช้ `ltFold` เดิม · ค่าเริ่มต้นพับ) อยู่ท้ายทุกแท็บ (เหนือแถบ "หลักฐาน & แหล่งที่มา") · เรียง A→Z ตาม `k` (`localeCompare`) · แต่ละแถว **คำ** — ความหมาย · ท้ายรายการเพิ่ม **ป้ายความน่าเชื่อ** เฉพาะตัวที่พบในเนื้อหาของการ์ดนี้ (ค่าคงที่ในแอป): `Mgmt` — คำพูด/คาดการณ์ของผู้บริหาร ยังไม่เกิดจริง · `Inference` — ผู้วิเคราะห์ตีความจากหลักฐาน · `Assumption` — สมมติฐานเรื่องอนาคต · `Unknown` — ยังไม่รู้ (ไม่เปิดเผย/หาไม่เจอ) · ข้อความที่ไม่มีวงเล็บ = Fact/Calc จากงบ · ไม่มี terms และไม่มีป้าย = ไม่แสดงแถบนี้ (n นับรวมป้ายด้วย)
