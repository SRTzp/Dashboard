## 1. ที่เก็บ (ระดับผู้ใช้ ที่เดียวกับ routine / newsEvents = settings ของ `acctList[0]` ผ่าน `tdSettings()`)
- `brokerList: [{id, name}]` · ไม่มี field = ค่าเริ่มต้น `[{id:'XM',name:'XM'},{id:'IC',name:'IC'},{id:'Pi',name:'Pi'}]`
- `satAssetCfg: {<assetKey>: {label?, hidden?}}` · ไม่มี = ใช้ `label` ใน `SAT_ASSETS` · `hidden` = false
- **`id` ของโบรก และ key ของสินค้า ไม่เปลี่ยนตลอดอายุ** — เปลี่ยนชื่อ = เปลี่ยนแค่ `name` / `label` · ค่าตั้งรายบัญชี `book.settings.brokers[<id>]` · ไม้ (`broker`) · slot ในแผน ยังเก็บ `id` เดิม
- ทุกจุดที่แสดงชื่อโบรก/สินค้า ใช้ฟังก์ชันเดียว: `brokerName(id)` (ไม่พบใน list → แสดง id เดิม) · `sat7dLabel(key)` อ่าน `satAssetCfg` ก่อน · ห้ามแสดง id/key ตรง ๆ ที่ไหนอีก (ไล่ทั้งไฟล์: การ์ดแผน · แถวไม้ · Journal · Today · Strategy · ฟอร์มเพิ่มไม้ · หน้าตั้งโบรก · Port)
- `SAT7D_BROKERS` / `SAT7D_LABEL` ที่เป็นค่าคงที่ตอนโหลด → เปลี่ยนเป็นฟังก์ชันอ่านค่าปัจจุบัน (หรือคำนวณใหม่เมื่อ settings เปลี่ยน) · `SAT7D_DEFAULT_BROKERS` คงไว้เป็นค่าเริ่มต้นของ XM/IC/Pi เท่านั้น

## 2. หน้า "ตั้งค่าโบรก · ขนาดสัญญา" (`sat7dBrokerOpen`)
**ส่วนใหม่บนสุด `โบรก`** (ใช้ร่วมทุกบัญชี):
- แถวละโบรก: ช่องชื่อ (แก้ได้) · ปุ่ม `ลบ` · ท้ายรายการ: ช่องชื่อใหม่ + `＋ เพิ่มโบรก`
- ชื่อ: ตัด space หัวท้าย · 1–20 ตัวอักษร · ห้ามซ้ำ (ไม่สนตัวพิมพ์) · ผิด = ข้อความเตือนใต้ช่อง ไม่บันทึก
- เพิ่ม: `id` สร้างครั้งเดียวจากชื่อ (ตัวอักษร/ตัวเลข · ซ้ำ id เดิม → ต่อท้าย `-2`) · ไม่มีค่าเริ่มต้นสัญญา (ผู้ใช้กรอกเอง)
- ลบ: ได้เฉพาะเมื่อ **ไม่มีบัญชีไหนติ๊กใช้** และ **ไม่มีไม้ที่เปิดอยู่ / slot ในแผนที่ยัง active อ้างถึง** · ไม่ผ่าน → ข้อความ `ลบไม่ได้ — ยังใช้อยู่ที่ {บัญชี / ไม้}` · ผ่าน → ยืนยัน 1 ครั้ง · ไม้ที่ปิดแล้วที่อ้าง id นี้ยังแสดง id เดิม (ไม่ error)
- ต้องเหลือโบรกอย่างน้อย 1 ตัว

**ส่วนใหม่ `สินค้า Sat`** (ใช้ร่วมทุกบัญชี):
- แถวละสินค้า (4 ตัวเดิม): key (สีเทา แก้ไม่ได้) · ช่อง `ชื่อที่แสดง` · สวิตช์ `ซ่อน`
- ชื่อที่แสดง: 1–12 ตัวอักษร · ห้ามซ้ำกับสินค้าอื่น · ว่าง = กลับเป็นชื่อเดิม
- ซ่อน: ทำได้เฉพาะเมื่อสินค้านั้น **ไม่มีไม้ที่เปิดอยู่ และไม่มีแผนที่ Activate อยู่ (ทุกบัญชี)** · ไม่ผ่าน → เตือนพร้อมเหตุผล · ต้องเหลือสินค้าที่ไม่ซ่อน ≥ 1

**ส่วนรายบัญชี (เดิม):** วนตาม `brokerList` แทนค่าคงที่ · แถวสินค้าแสดงเฉพาะที่ไม่ซ่อน (ค่าตั้งของสินค้าที่ซ่อน **เก็บไว้ ไม่ลบ** ตอนบันทึก) · ชื่อโบรกในแถว = `name`
- จัดหน้าใหม่ให้มือถือ 390px ไม่ล้น: ช่องตัวเลขใช้สไตล์ช่องกรอกของหน้าตั้งค่า (font ≥ 16px) · แถวสินค้าขึ้นบรรทัดใหม่ได้ (เลิกกำหนดความกว้างเป็น px ตายตัว)
- ปุ่ม `บันทึก` เดิม = บันทึกทั้ง 3 ส่วนพร้อมกัน · ยกเลิก = ไม่มีอะไรเปลี่ยน

## 3. ผลของ "ซ่อนสินค้า"
- ไม่แสดง: ช่องสินค้าใน Strategy สัปดาห์นี้ · ปุ่ม `+ แผน` / ตัวเลือกสินค้าตอนสร้างแผน · ฟอร์มเพิ่มไม้ Sat · แถวสินค้าในหน้าตั้งโบรก · การเช็ก "ยังไม่ตั้ง Bias สัปดาห์" และเช็กแผน Sat รายวันใน Today (`TD_SAT_MK` · ตัวนับ ✓/✕ ไม่นับสินค้าที่ซ่อน)
- ยังแสดงตามเดิม: ไม้เก่า/ปิดแล้ว · Journal · สถิติ · Port · ข้อมูล Bias สัปดาห์ที่บันทึกไว้แล้ว (ไม่ลบ)
- เลิกซ่อน → ทุกอย่างกลับมา ข้อมูลเดิมครบ
