## 1. ตัดแถบสถานะ + กลุ่ม "ปกติ" → บรรทัดเดียว + ตาราง "ดูตัวเลข"
- **ลบ** แถบชิปสถานะเร็ว (DD/heat/ไม้ใหม่/f/ชั้น 2 ต่อบัญชี) และกลุ่ม 🟢 ปกติ ทั้งหมด
- ท้ายหน้าใส่ **บรรทัดเขียวบรรทัดเดียว**: `✓ อื่น ๆ ปกติ — DD · heat · ไม้ใหม่ · ชั้น 2 · f · fundflow` (มือถือ: `✓ อื่น ๆ ปกติ`) + ลิงก์ขวา `ดูตัวเลข`
  - ถ้ามีเรื่องผิดปกติในหมวดเหล่านี้ (ข้อ 2) → บรรทัดนี้ตัดคำของหมวดนั้นออก (เช่น heat ผิดปกติ → `✓ อื่น ๆ ปกติ — DD · ไม้ใหม่ · …`) · ผิดปกติทุกหมวด = ไม่แสดงบรรทัดนี้
- `ดูตัวเลข` = พับ/กาง **ตารางเล็ก** (ค่าเริ่มต้นพับ · จำสถานะในหน่วยความจำของหน้า): แถว = บัญชี · คอลัมน์ `DD Core · DD Sat · heat Sat · ไม้ใหม่ Sat · ชั้น 2 Core` (บัญชีที่ไม่มีถังนั้น = `—`) · ใต้ตาราง 1 บรรทัด: `ประตู f: {สถานะเดิม} · fundflow อัปเดต {d MMM}` · ค่าที่ผิดปกติในตาราง = ตัวสีเหลือง/แดง · ค่าทั้งหมดใช้ฟังก์ชันเดิม (ห้ามคิดใหม่)
- จอ ≤ 430px: ตารางไม่ล้นแนวนอน (ย่อหัวคอลัมน์ได้ เช่น `DD C · DD S · heat · ไม้ใหม่ · ชั้น 2`)

## 2. ผิดปกติ = ขึ้นเป็นงาน (เพิ่มจาก TD1 · ทุกบัญชี)

| 🟡 | ไม้ใหม่ Sat ครบโควตา | `nNew ≥ newMax` | `ไม้ใหม่ Sat {บัญชี} ครบ n/m สัปดาห์นี้` → แท็บแผน |

## 3. เช็กแผน Sat วันนี้ — ✓ / ✕ + Focus
- แต่ละตลาด 3 สถานะ: ยังไม่ดู (ค่าเริ่มต้น) · **✓ มีแผน = Focus วันนี้** · **✕ วันนี้ไม่มีแผน** · กดปุ่มเดิมซ้ำ = กลับเป็นยังไม่ดู · กดอีกปุ่ม = สลับ
- หน้าตา (ตามม็อกอัป): ช่องต่อตลาด = ชื่อ + ปุ่ม `✓` + ปุ่ม `✕` (ปุ่ม ≥ 34px) · ✓ = ช่องเขียว ปุ่ม ✓ ทึบเขียว · ✕ = ช่องเทาจาง ชื่อขีดฆ่า ปุ่ม ✕ ทึบเทา · กดชื่อ = ไปการ์ด Strategy ตลาดนั้น (เดิม) · ป้าย `n/4` = จำนวนที่ตัดสินแล้ว
- จอใหญ่ 4 ช่องแถวเดียว · **จอ ≤ 430px ตาราง 2×2** · ไม่ล้น · `elementFromPoint` ของปุ่ม = ปุ่ม
- ตัดสินครบทุกตลาด (✓ หรือ ✕) = แถวนี้หายจากรายการ (เหลือบรรทัด Focus ข้อ 4)
- **ชื่อแสดง: XAU · BTC · S50 · Brent** (เฉพาะป้ายบนจอในแท็บ Today + ค่าตั้ง Daily routine · ข้อมูล/รหัสข้างในเดิม XAUUSD/BRENT ไม่เปลี่ยน)
- เก็บ: `routineLog[วัน].satState = {XAUUSD:'ok'|'no', …}` (ไม่มีคีย์ = ยังไม่ดู) · log เดิมที่เป็น `sat:[…]` (TD1) อ่านเป็น `'ok'` (ไม่ migrate เขียนทับ · เขียนครั้งต่อไปใช้รูปใหม่)
- ✕ **ไม่กระทบงานอื่น** — แถว "Bias ยังไม่ประเมิน" ยังแสดงทุกตลาดที่ไม่มี Bias (ผู้ใช้: Strategy ต้องทำเป็นประจำทุกสัปดาห์ ได้ฝึกด้วย)

## 4. บรรทัด Focus วันนี้ (ใต้หัว "ต้องทำ")
- แสดงเมื่อมีตลาดที่ตัดสินแล้วอย่างน้อย 1 ตัว (จ.–ศ.): `Focus วันนี้: [XAU] [BTC] · ไม่มีแผน: Brent · ยังไม่ดู: S50` · ชิป Focus สีเขียว กดได้ = ไปการ์ด Strategy · ส่วนที่ว่างไม่แสดง (เช่น ไม่มีตัวไหน ✕ = ไม่มีคำ "ไม่มีแผน")
- ทุกตัว ✕ = `วันนี้ไม่มีแผน Sat`
- มือถือ: `Focus: [XAU] · ยังไม่ดู BTC · S50` (ตัด "ไม่มีแผน" ออกถ้าบรรทัดยาวเกิน 1 บรรทัด)

## 5. การบ้านหุ้น วันละ 1 ตัว (ใหม่ · จ.–ศ.)
- แถวในกลุ่ม 🟡 (ใต้เช็กแผน Sat): `📚 การบ้านหุ้นวันนี้: {T}` + บรรทัดรอง `{เหตุผล}` · ปุ่ม `✓ เสร็จ` · ปุ่ม `เปลี่ยนตัว` · กดชื่อ/แถว = `wlOpen(T, 'ov')` · ป้ายช่วง: `.BK` → Selection TH · อื่น → Selection US

  2. Research Card เก่าสุด (`research_card.as_of` · เหตุผล `Research เก่า n วัน`)

  - ตัวที่เสนอของวัน **คงที่ทั้งวัน** (เก็บ pick ไว้ใน log ของวันนั้น) จนกว่าจะกด "เปลี่ยนตัว" = ตัวถัดไปในลำดับ (วนกลับตัวแรกเมื่อสุด)

- **ผู้ใช้กำลังปรับโครงข้อมูล Watchlist** → อ่านแค่ ticker ใน Watchlist + `research_card.as_of` ผ่านฟังก์ชันที่มีอยู่ (`wlRowsAll`/`wlDocMap` ที่ TD1 ใช้) · แยกตัวเลือกหุ้นไว้ในฟังก์ชันเดียว `tdHomeworkCandidates()` ให้แก้เกณฑ์ทีหลังง่าย · ห้ามเขียนอะไรลง watchlist doc
