## 1. จำว่าเอา Asset ออกจากสัปดาห์แล้ว (แทนข้อตีความ WA1fix)
- ตอนนี้: เอา Asset ที่มีแผน/ไม้เปิดออกจาก pick → auto-pick (`satAutoPickCands` / ตัว sync) ใส่กลับเองรอบถัดไป
- ใหม่: `waRemove` เก็บ `satWeekDrop[สัปดาห์] = [keys]` (settings ของ `acctList[0]` เหมือน `satWeekPick` · เก็บ 12 สัปดาห์ล่าสุด) → auto-pick **ข้ามตัวที่อยู่ใน drop ของสัปดาห์นั้น** · Asset นั้นมีแผน/ไม้ → ไปแถบ `ไม้ค้าง · ไม่ได้เลือกสัปดาห์นี้` (ทำงานตาม WA1 เดิม: จัดการไม้เดิมได้ · ห้ามเปิดไม้/Activate ใหม่)
- เพิ่มกลับเอง (`＋ Asset` / `＋ วางแผน` จาก Flow หรือไอเดีย) → เอาออกจาก drop
- สัปดาห์ใหม่: drop เริ่มว่าง (auto-pick ทำงานตามปกติ)

## 2. แท็บ AI vs เรา — ปุ่มเฉพาะแถวที่ต้องตัดสิน (แทนปุ่ม 3 ปุ่มทุกแถว)
- แถวที่ไม่มีป้าย (ตรงกัน / AI ว่าง): **ไม่มีปุ่ม** · ช่อง "เรา" แตะเพื่อแก้ได้ทันที (inline · Enter/blur = บันทึก · Esc = ยกเลิก) · ช่องมีไอคอน `✎` เล็กสีจาง
- แถว `ต่าง` / `ขาด` ที่ยังไม่ตัดสิน: ปุ่มเล็ก 2 ปุ่ม **บรรทัดเดียว** ใต้แถว: `← ใช้ของ AI` · `คงของเรา` (= รับทราบเดิม · `ack`)
  - ตัดสินแล้ว (ใช้ของ AI / คงของเรา / แก้ช่องเราจนตรงกับ AI) → ป้ายจางลง + ปุ่มหาย · badge แท็บลด
- ตัดปุ่ม `เขียนของเรา` (แตะช่องแทน) · ค่า `me` / `ack` / badge / จุดเหลือง ทำงานเหมือนเดิม
- 390px: แท็บนี้ยาวรวม ≤ 600px กับข้อมูลตัวอย่าง 6 แถว (เดิม ~1,000)

## 3. ขัดเกลา
- ตาราง AI vs เรา + ฟอร์ม `＋ ไอเดีย` ใช้ฟอนต์ mono กับภาษาไทย → ใช้ฟอนต์หลักของแอป (mono เฉพาะตัวเลข/ราคา ถ้ามี)
- ฟอร์มเพิ่ม Product (แท็บ Product) ไม่มีสไตล์ (input/select ดิบ) → ใช้สไตล์ช่องกรอกเดียวกับฟอร์มอื่นของแอป
- ป้ายซ้ำในแถว Product (เช่น `Option` `Option` · `สูง` + `Futures`) → แสดง ประเภท 1 ป้าย + Leverage 1 ป้าย (ไม่ซ้ำ)
- การ์ด Strategy ที่ 390 (ภาพ `tr1-plan-link-390`): การ์ด Asset แคบ ชื่อตัดเป็น `XAU…` และ `Long · ขนาดไม้ l…` → การ์ดเต็มความกว้างเมื่อจอแคบ ชื่อ Asset ไม่ถูกตัด
