# ST1 — กติกา Sat: ออกกำไร 2 ขั้น · R:R ≥ 1.5 · งดเปิดไม้ช่วงข่าว CPI/NFP · เช็กลิสต์ก่อนข่าว · เทส 51

> ต่อจาก ID4 · กติกาที่ผู้ใช้ตัดสิน 6 ต.ค. (ห้ามตีความเพิ่ม):
> 1. **TP:** ถึง TP แรก (= ขอบใกล้ของ TP zone · ค่า `idea.tp` เดิม) ออก 50% แล้วเลื่อน Stop ส่วนที่เหลือมาจุดเข้า · ส่วนที่เหลือไป TP2 (= ขอบไกลของ TP zone)
> 2. **R:R ขั้นต่ำ** = |TP แรก − Entry| ÷ |Entry − Stop| **≥ 1.5** · ต่ำกว่า = **บล็อก** การบันทึก order (แบบเดียวกับ สวน Bias / พัก DD — ไม่มีทางลัด)
> 3. **ข่าว CPI / NFP:** ห้ามเปิดไม้ใหม่ **ทุก asset ของ Sat** ตั้งแต่ **1 ชม. ก่อนข่าว** จน **แท่ง 30 นาทีที่ข่าวออกปิด** (CPI 19:30 → 18:30–20:00) · หลังแท่งปิด เข้าได้ตามปกติ
> 4. **ไม้ที่ถืออยู่ก่อนข่าว (CPI / NFP / FOMC):** ยกเลิก limit ที่ค้าง · ไม้มีกำไร → เลื่อน Stop มาจุดเข้า · ไม้ยังไม่กำไร → ถือตามกฎ · เช็กว่า Stop อยู่ที่ broker จริง
> 5. **วันข่าว:** ผู้ใช้กรอกเองในหน้าตั้งค่า (ไตรมาสละครั้ง) — แอปไม่ดึงจากเว็บ
>
> สำรองก่อนแก้: `index.backup-pre-ST1.html` · `tests/_bk_st1/` · ห้ามแตะ core-size.js เว้นแต่จำเป็น (ถ้าแตะต้อง sync + รายงาน) · ห้ามย้อนงานรอบก่อน · ข้อ MR (ปิดไปแล้วใน SR1) ไม่ต้องแตะ

## 1. วันข่าวในตั้งค่า
- หน้าตั้งค่าระบบ ใกล้ส่วน Daily routine: ส่วนใหม่ `วันข่าวสำคัญ (Sat)` · รายการแถว: วันที่ (เวลาไทย ตามที่ปฏิทินเวลาไทยแสดง) · ประเภท `CPI` / `NFP` / `FOMC` · เวลา (เติมให้อัตโนมัติ แก้ได้) · ปุ่มลบแถว · ปุ่ม `＋ เพิ่ม`
- เวลาเติมอัตโนมัติตามช่วงเวลาออมแสงสหรัฐ (DST: อาทิตย์ที่ 2 ของ มี.ค. → อาทิตย์ที่ 1 ของ พ.ย.): CPI / NFP = **19:30** ช่วง DST · **20:30** นอก DST · FOMC = **01:00** ช่วง DST · **02:00** นอก DST (วันที่ที่กรอกคือวันไทยที่ข่าวออก)
- เก็บที่ settings ระดับผู้ใช้ที่เดียวกับ routine (`tdSettings()` / settings ของ `acctList[0]`) field `newsEvents: [{date:'YYYY-MM-DD', kind:'CPI'|'NFP'|'FOMC', time:'HH:MM'}]` · ตรวจรูปแบบวัน/เวลา · ซ้ำวัน+ประเภท = เตือน ไม่บันทึกซ้ำ · วันที่ผ่านไปเกิน 30 วัน ซ่อนจากรายการ (ไม่ลบ)
- ไม่มีวันข่าวในอีก 14 วันข้างหน้า → บรรทัดเตือนเล็กในส่วนนี้ `ยังไม่ได้กรอกวันข่าวช่วง 2 สัปดาห์ข้างหน้า` (ไม่ขึ้น Today)

## 2. งดเปิดไม้ช่วง CPI / NFP (การ์ดแผน Sat)
- ช่วงงด = `[เวลาข่าว − 60 นาที, เวลาข่าว + 30 นาที)` ตามเวลาไทย (ใช้นาฬิกาเดียวกับส่วนอื่นของแอป) · ใช้กับ CPI / NFP เท่านั้น (FOMC = ข้อ 4 อย่างเดียว ไม่งด)
- อยู่ในช่วงงด → `satV3PlanAcctCalc` ใส่เหตุผล `ช่วงข่าว {CPI} {18:30–20:00} — งดเปิดไม้ใหม่ (เปิดได้หลัง 20:00)` · ไม่ ready ทุกบัญชี · `satV3SaveSlot` กันซ้ำที่ฟังก์ชัน (แบบ `offBias` / `ddBlock`) · ไม่มีทาง "รวมด้วย (นอกแผน)"
- นอกช่วง → ทำงานเดิม · การ์ดที่ Activate ไว้ก่อนช่วงงดไม่ถูกยกเลิก (แค่บันทึก order ไม่ได้ระหว่างช่วง)

## 3. TP 2 ขั้น + R:R ขั้นต่ำ
- TP แรก = `idea.tp` (กลไกเดิม: ขอบใกล้ของ TP zone ข้อที่ Activate · ผู้ใช้แก้ได้) · **TP2** = ขอบไกลของ TP zone ข้อเดียวกัน (ฟังก์ชันคู่กับ `satV3TpNear`) · ไม่มี TP zone / zone เป็นจุดเดียว → TP2 = ว่าง
- R:R = |TP แรก − Entry| ÷ |Entry − Stop| · ไม่มี TP แรก → **บล็อก** (`ต้องมี TP แรกก่อน — R:R ขั้นต่ำ 1.5`) · R:R < 1.5 → บล็อก `R:R {1.2} ต่ำกว่า 1.5 — ปรับ Entry / Stop / TP` · TP อยู่ผิดฝั่งของ Entry → บล็อก
- แสดงในบล็อก Activate ของการ์ด: `R:R {x.x}` (เขียว ≥ 1.5 · แดง < 1.5) + บรรทัดสั่งงาน `TP1 {tp} ออก 50% → เลื่อน Stop มา {entry} · TP2 {tp2} ส่วนที่เหลือ` (ไม่มี TP2 → `ส่วนที่เหลือ: ตามแผน`)
- บันทึกไม้: เพิ่ม field `tp2` ในไม้ (ไม้เก่าไม่มี = ไม่เป็นไร) · บรรทัดไม้ Sat ที่เปิดอยู่ (แผง/แถวไม้) แสดง `TP1 · TP2` · ปิดบางส่วนใช้ modal scale-out เดิม (ไม่แก้)
- เติมไม้ (PY1) / ไม้ MR: ไม่ใช้ R:R gate รอบนี้

## 4. เช็กลิสต์ก่อนข่าว (แท็บ Today)
- วันที่มีข่าว (CPI / NFP / FOMC ตามตั้งค่า · FOMC 01:00 = ขึ้นตั้งแต่วันก่อนหน้า) **และ** มีไม้ Sat เปิดอยู่ หรือ order Sat ที่ยังรอเข้า → แถวกลุ่ม `r` ด่วน:
  `📰 {CPI} {19:30} — ก่อนข่าว: ยกเลิก limit ที่ค้าง · ไม้กำไร → Stop มาจุดเข้า · ไม้ยังไม่กำไรถือตามกฎ · เช็ก Stop ที่ broker` · sub = รายชื่อไม้/บัญชี · แตะ = ไปหน้า Sat (แผงไม้)
- วันข่าว CPI / NFP ไม่มีไม้เปิด → แถวกลุ่ม `a` 1 บรรทัด `📰 {CPI} {19:30} — งดเปิดไม้ใหม่ {18:30–20:00}` (ไม่มีวันข่าว = ไม่มีแถว · ปกติ = เงียบ)
- หลังเวลาข่าว + 30 นาที → แถวของข่าวนั้นหาย
- แถวข่าวไม่นับในเพดาน 2 แถวของ Ideas (ID4)
