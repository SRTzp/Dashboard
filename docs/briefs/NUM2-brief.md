## 1. `luckyWins` / `goodLosses` ใช้เกณฑ์ BE เดียวกับป้าย (ต่อจาก NUM1)
- ตอนนี้ (~5976–5977): `realizedPnlOf(t)>0` / `<=0` → ไม้ +0.4 (ป้าย = BE) ถูกนับเป็น "ชนะแบบไม่ตามแผน"

- `pnlOutcome` คืน `null` (ยังไม่มี P&L) → ไม่นับทั้งคู่

## 2. sheet อัปเดตราคา (PX1): กันค่ากรอกเองเก่าทับราคาอัตโนมัติ
- ตอนนี้ (`corePxOpen` ~7776): ช่องเติมค่าที่กรอกเองเก่า (`_pxMan`) + วันที่ = ศุกร์ล่าสุด → ถ้ากด บันทึก โดยไม่แก้ ค่าเก่า (เช่น 100 ของ 26 ก.ย.) จะได้วันที่ใหม่ (2 ต.ค.) แล้วชนะ auto (105 · 2 ต.ค.) เพราะวันเท่ากัน = กรอกเองชนะ
- ใหม่:
  - การ์ดกำลังใช้ราคาอัตโนมัติ (`pxSrc==='auto'`) → ช่องเติม **ค่า auto** (close · ema10w) + วันที่ = `closeDate` ของ auto · บรรทัดใต้หัว: `ตอนนี้ใช้ราคาอัตโนมัติ — แก้ตัวเลขแล้วบันทึกเพื่อใช้ค่าที่กรอกเองแทน`
  - การ์ดใช้ค่าที่กรอกเอง (ไม่มี auto / auto เก่ากว่า / suspect) → เหมือนเดิม (ค่ากรอกเอง + ศุกร์ล่าสุด + บรรทัด "ราคาอัตโนมัติล่าสุด…" ถ้ามี)
- กติกาเลือกราคา (`coreApplyPx`) **ไม่เปลี่ยน** · การบันทึกยังเขียนเฉพาะค่าที่อยู่ในช่อง

## 3. ประตู f นับวันทำการด้วยเวลาไทย
- `ffBizDaysSince` (~14224) ใช้ `new Date()` เวลาเครื่อง → เครื่องที่ตั้งเขตเวลาอื่น (เดินทาง / เบราว์เซอร์ตั้งค่า UTC) นับผิดวันได้ช่วงเช้ามืด
