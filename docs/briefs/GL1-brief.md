## ข้อตัดสิน (ผู้ใช้ 8 ต.ค.)
- เป้า **แยกต่อบัญชี** (main / Family ไม่รวมกัน) · สกุลเงินเลือกต่อบัญชี ($ หรือ ฿)
- % = **จากจุดเริ่ม + มีวันครบกำหนด** + บอกเร็ว/ช้ากว่าเส้นทาง
- มูลค่าพอร์ต = **กรอกเองจากโบรก เก็บเป็นประวัติ** (ยอดรวมทุกโบรกของบัญชี) · ไม่คำนวณจากทุน/ไม้ในแอป
- วาง **บนสุดของแท็บ Today** · สลับ Daily | Weekly
- Daily = Routine เดิม (ช่วงเวลา · เช็กแผน Sat · การบ้าน) + **งานอื่นที่ตั้งเอง (ไม่มีเวลา)**
- Weekly ชุดเริ่มต้น 4 ข้อ แก้/เพิ่มได้ (ข้อ 4)

## 1. ที่เก็บ (settings ของ `acctList[0]` ที่เดียวกับ routine · เขียนผ่านทางเดียวกับ `tdLogWrite` / `tdCanWrite`)
- `goals: { [acctId]: {cur:'USD'|'THB', start:number, startDate:'YYYY-MM-DD', target:number, deadline:'YYYY-MM-DD'} }`
- `goalLog: { [acctId]: [{d:'YYYY-MM-DD', v:number}] }` — เรียงตามวัน · วันเดียวกันกรอกซ้ำ = แทนที่ · เก็บทั้งหมด (ไม่ตัด)
- `dailyExtra: [{id, name}]` — งานรายวันไม่มีเวลา (ชื่อ ≤ 30 ตัว · ≤ 8 ข้อ)
- `routineLog[วัน].extra: [id]` — ติ๊กงานอื่นของวันนั้น (ใช้ตัวตัด 60 วันเดิม)
- `weekTasks: [{id, name, auto:'bias'|'value'|'daily'|null, on:true|false}]` — ไม่มีค่า = ชุดเริ่มต้นข้อ 4
- `weekLog: { [วันจันทร์ ISO]: {done:[id]} }` — ติ๊กเองของงาน `auto:null` · เก็บ 26 สัปดาห์ล่าสุด (ตัดตอนเขียน)
- บัญชีที่ถูกลบ = ข้าม key ที่ไม่มีใน `acctList` (ไม่ลบข้อมูล)

## 2. แถบเป้าหมาย (การ์ด "🎯 เป้าหมาย Port")
- แสดงเฉพาะบัญชีที่ตั้งเป้า · ไม่มีบัญชีไหนตั้งเลย = แถวเดียว `ตั้งเป้าหมาย Port →` (ไปตั้งค่า) · ปุ่ม `＋ กรอกค่าพอร์ต` ที่หัวการ์ด
- ต่อบัญชี 3 บรรทัด (ตามม็อกอัป · แต่ละบรรทัดไม่ตัดขึ้นบรรทัดใหม่ที่ 390px):
  1. `ชื่อบัญชี` · `ค่าตอนนี้ → เป้า · วันครบ (d MMM yy ไทย)` · `% ความคืบหน้า` (จำนวนเต็ม)
  2. แถบความคืบหน้า + ขีดดำ = ตำแหน่งที่ควรอยู่ตามเส้นทาง
  3. สถานะเส้นทาง · `ต้องโต x.x%/ปี จากนี้` · `กรอก <วัน>` (เก่ากว่า 7 วัน → สีเหลือง + `(n วัน)`)
- สูตร (as-of = วันของค่าล่าสุดใน `goalLog` ที่ ≤ วันนี้ · ไม่ใช่วันนี้ — กันเทียบค่าเก่ากับเส้นทางวันนี้):
  - `now` = ค่าล่าสุด · ไม่มีค่าเลย → `now = start` · as-of = startDate · บรรทัด 3 = `ยังไม่กรอกค่าพอร์ต`
  - `progress = (now − start) / (target − start) × 100` · แถบตัดที่ 0–100 · ตัวเลขแสดงจริง (ติดลบได้)
  - เส้นทาง = โตแบบทบต้นคงที่: `k = ln(target/start) / วัน(startDate→deadline)` · `expected = start × e^(k × วัน(startDate→as-of))`
  - `vs = now / expected − 1` · |vs| < 1% → `ตามเส้นทาง (±x.x%)` สีปกติ · vs ≥ 1% → `เร็วกว่าเส้นทาง +x.x%` (teal) · vs ≤ −1% → `ช้ากว่าเส้นทาง −x.x%` (amber)
  - `ต้องโต = (target / now)^(365 / วัน(as-of→deadline)) − 1`
  - ขีดดำ = `(expected − start)/(target − start)` ตัด 0–100
  - ขอบ: `now ≥ target` → `% ≥ 100` + บรรทัด 3 = `✓ ถึงเป้าแล้ว` (ไม่แสดงต้องโต) · as-of ≥ deadline และยังไม่ถึง → `เลยกำหนด` (amber) แทนต้องโต · `now ≤ 0` → ไม่คำนวณต้องโต (`—`)
- รูปเงิน: `$145.0k` · `฿2.38M` (< 1M = k ทศนิยม 1 · ≥ 1M = M ทศนิยม 2) · ตัวเลขไม่ใช้ mono

## 3. Sheet `＋ กรอกค่าพอร์ต`
- วันที่ (ค่าเริ่ม = วันนี้ไทย · ห้ามวันอนาคต) + ช่องต่อบัญชีที่ตั้งเป้า (ป้ายสกุล · placeholder `ล่าสุด <ค่า>`) · ช่องว่าง = ไม่บันทึกบัญชีนั้น · ค่าต้อง > 0 · ตัวเลขรับจุลภาคได้ · `inputmode="decimal"` · font ≥ 16px (กัน iPhone ซูม)
- บันทึกแล้วปิด sheet + แถบอัปเดตทันที

## 4. ตั้งค่าระบบ
**ส่วนใหม่ "เป้าหมาย Port"** (ต่อบัญชี): สกุล · เป้า · วันครบ · ค่าเริ่ม + วันเริ่ม (ค่าเริ่มต้นของช่อง = ค่าล่าสุดใน `goalLog` + วันนี้ ถ้ามี) · ปุ่ม `ลบเป้า` (ยืนยัน · ไม่ลบ `goalLog`) · ตรวจ: target > start > 0 · deadline > startDate · ไม่ผ่าน = ข้อความ ไม่บันทึก
- รายการประวัติค่าพอร์ตของบัญชี (ล่าสุดก่อน · ≤ 12 แถว + `ดูทั้งหมด`) · ลบรายแถวได้ (ยืนยัน)

**ส่วน Daily routine เดิม** เพิ่ม:
- `งานรายวันอื่น (ไม่มีเวลา)`: เพิ่ม / เปลี่ยนชื่อ / ลบ / เรียงลำดับ (ใช้รูปแบบเดียวกับรายการช่วงเวลาเดิม)
- `งานรายสัปดาห์`: ชุดเริ่มต้น 4 ข้อ —
  1. `ตั้ง Bias สัปดาห์ Sat ครบ` · `auto:'bias'` — ครบเมื่อทุกตัวใน `tdRoutine().satDaily` มี `satwWeek(wpWeekKey(), asset).bias` ∈ Long / Short / None · ตัวเลข `n/N`
  2. `กรอกค่าพอร์ต + ทบทวน Core` · `auto:'value'` — ครบเมื่อทุกบัญชีที่ตั้งเป้ามีค่าใน `goalLog` ภายในสัปดาห์นี้ (จ.–อา.) · `n/N บัญชี` · ไม่มีบัญชีตั้งเป้า = ซ่อนข้อนี้ (ไม่นับ)
  3. `ทบทวน Journal สัปดาห์นี้` · `auto:null` (ติ๊กเอง)
  4. `Daily ครบ ≥ 4/5 วัน` · `auto:'daily'` — นับวัน จ.–ศ. ของสัปดาห์นี้ที่ Daily ≥ 80% · `n/4`
- งาน auto: เปลี่ยนชื่อได้ · ปิด/เปิด (`on`) ได้ · ลบไม่ได้ · งานที่เพิ่มเอง = `auto:null` ลบได้ · ≤ 10 ข้อ · ปุ่ม `คืนค่าเริ่มต้น`

## 5. สลับ Daily | Weekly (ใต้การ์ดเป้า · ปุ่มสูง ≥ 40px)
- ป้ายปุ่มมี %: `Daily · 50%` · `Weekly · 50%` · จำแท็บที่เลือกต่อเครื่อง (localStorage ห่อ try/catch · ค่าเริ่ม Daily)
- **Daily** (วันนี้ไทย):
  - ตัวหาร = ช่วงเวลาทุกช่องของวันนี้ + ทุกตัวใน `satDaily` + การบ้าน (เฉพาะวันที่มี `hw.pick`) + `dailyExtra` ทุกข้อ
  - ตัวตั้ง = ช่องที่ติ๊ก (`slots`) + Sat ที่เป็น `ok` **หรือ** `no` (✕ = ดูแล้ว นับว่าทำ) + `hw.done` + `extra` ที่ติ๊ก
  - หัว: `วันนี้ <วัน d MMM>` · `n/N · x%` (ปัดเป็นจำนวนเต็ม) · แถบ · ชิปแยกหมวด `ช่วงเวลา a/b` `เช็กแผน Sat a/b` `การบ้าน a/b` `งานอื่น a/b` (หมวดที่ตัวหาร 0 = ไม่แสดง)
  - รายการ `งานอื่นวันนี้` ติ๊กได้ตรงนี้ (เขียนผ่าน `tdLogWrite`) · ช่วงเวลา/Sat/การบ้าน ติ๊กที่เดิมด้านล่าง (ไม่ซ้ำ)
  - เสาร์–อาทิตย์: ปุ่ม `Daily · วันหยุด` · แผง = `วันหยุด — ไม่มีงานรายวัน` (ยังติ๊กงานอื่นไม่ได้)
- **Weekly** (จ.–อา. ของสัปดาห์นี้ · `tdMonday`):
  - ตัวหาร = งานที่ `on` (ข้อ 2 ซ่อนถ้าไม่มีเป้า) · ตัวตั้ง = auto ที่ครบ + ติ๊กเองใน `weekLog`
  - แถว: ช่องติ๊ก (auto = เส้นประ กดไม่ได้) · ชื่อ · ขวา `n/N` หรือ `กดเอง` · ทั้งแถวบรรทัดเดียว
  - แท่ง จ.–ศ. = Daily % ของแต่ละวัน (≥ 80% teal · < 80% amber · วันอนาคตว่าง · วันนี้ตัวหนา)
  - Daily % วันก่อนหน้า: ใช้ log ของวันนั้น + **ค่าตั้ง routine / dailyExtra ปัจจุบัน** เป็นตัวหาร (ไม่ snapshot · ยอมรับ)
- "ปกติ = เงียบ" ไม่ใช้กับส่วนนี้ (ผู้ใช้ขอให้เห็นเสมอ) แต่ห้ามดันส่วนเดิมของ Today จนรก: การ์ดเป้า + สลับ + แผง ≤ ~1 จอ iPhone เมื่อมี 2 บัญชี
