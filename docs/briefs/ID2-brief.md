## 5. คัดลอก Handoff (แอปประกอบข้อความเอง · ไม่เรียก AI)
- **Handoff (ฝั่งได้ → living-thesis lite):**
```
living-thesis lite · {SYM} ({market})
จากไอเดีย: {ชื่อไอเดีย} ({id} · idea@1 {date})
ไอเดีย: {one_liner รวมเป็นประโยคเดียว}
ส่วน value chain: {segments คั่นด้วย ·}
ทำไมตัวนี้: {why_this}
นัยต่อทั้งบริษัท: {exposure}
ไม่ได้ประโยชน์แม้ไอเดียถูก ถ้า: {fail_even_if_right}
แหล่งยืนยัน: {relevance_src}
คำถามให้ Thesis:
- {questions[] ทีละบรรทัด}
สัญญาณพักของไอเดีย:
- {kill[].signal (level)}
```
- **Handoff (update · ฝั่งเสีย → living-thesis update · ใช้เป็นหลักฐานฝั่ง bear):** หัว `living-thesis update · {SYM} · หลักฐานฝั่ง bear จากไอเดีย` + ชื่อไอเดีย/id/date + ไอเดีย + `เสียประโยชน์เพราะ: {why}` + `แหล่ง: {src}` + สัญญาณพัก · ท้าย: `ไอเดียไม่เปลี่ยน Thesis เอง — ใช้ประกอบการ update เท่านั้น`
- ช่องที่ว่างในไอเดีย → ตัดบรรทัดนั้นทิ้ง (ห้ามมี "undefined" / "null" / บรรทัดหัวเปล่า)
- คัดลอกด้วย clipboard (ล้ม → แสดงข้อความในกล่องให้เลือกคัดลอกเอง) · ข้อความยืนยัน `คัดลอกแล้ว — วางให้ living-thesis`

## 6. Value chain / จุดสี
- แท็บ Value chain: กล่องแดงบนสุด `หุ้นของเราที่อยู่ฝั่งเสีย: XYZ · …` เมื่อ `losers[]` ตรงกับหุ้นใน Watchlist (ถืออยู่ = มีจุดสีบัญชีแบบแถว Watchlist) · ไม่มี = ไม่แสดง · ตัวเลขส้มบนแท็บ Value chain = จำนวนตัว
- จุดสีรายการ Ideas (ปรับ `ideaDot`): 🟡 = สัญญาณพัก watch **หรือ** มีบริษัทสถานะ ศึกษา ที่ **ยังไม่อยู่ Watchlist** **หรือ** มีหุ้นของเราฝั่งเสีย · 🔴 เดิม · ส่งเข้า Watchlist ครบแล้ว + ไม่มีเรื่องอื่น = ⚪

## 7. asset อื่น (แท็บ สรุป · ข้อ 6b ของ spec)
- มี `assets[]` → 1 บรรทัด `asset อื่น: [Brent ↑] [S50 ผันผวน]` (สูงสุด 3 ตัว · เกินตัดทิ้ง) · ป้าย Inference สีเทาเหมือนเดิม · `why` อยู่ใน title
- แตะป้าย → ไปแท็บ Flow ที่การ์ด Playbook ของ asset นั้น (หาไม่เจอ = แค่เปลี่ยนแท็บ ไม่ error) · ชื่อ asset แสดงแบบเดียวกับ Today (XAU · BTC · Brent · S50)
- ไม่แสดงที่อื่น (รายการ / Watchlist / Candidates / Today) · การ์ด Playbook ในแท็บ Flow ไม่เพิ่มอะไรบนหน้าการ์ด
- ฝั่ง Flow: ใน full report ของ Playbook เพิ่มบรรทัดพับ `ไอเดียที่เกี่ยว (n)` **ท้ายสุด** (n = ไอเดียที่นับตามข้อ 0 ที่มี asset นั้น · แตะชื่อ = เปิดไอเดีย) · n = 0 → ไม่แสดง
