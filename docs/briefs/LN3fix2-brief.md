## 1. Core — ไม้เร่ง + Risk ต่อไม้ (กลยุทธ์ Winners เท่านั้น · Ladder ไม่เปลี่ยน)
**กติกาที่ผู้ใช้ตัดสิน**
1. **2 ชั้นต่อการ์ด:** `Base` (ไม้แรก + ไม้เติมปกติ) ใช้ **SL Base** ร่วมกัน · `ไม้เร่ง` (ติ๊กตอนเติมไม้) ใช้ **SL เร่ง** ร่วมกันในชั้นเร่ง
2. **งบแยก:** งบเสี่ยง Base ต่อหุ้น (ค่าตั้ง · ผู้ใช้ตั้งใช้จริง ≈ 1.0%) · **งบเสี่ยงไม้เร่ง** ตัวเลขแยก (ค่าเริ่ม 0.35% · ข้อความแนะนำ "≈ 1/3 ของงบ Base" — คิดจาก **Risk** ไม่ใช่จากขนาด) · ทั้งคู่ × FF จริงของสัปดาห์
3. **งบที่เหลือของชั้น** = งบ × f − ความเสี่ยงค้างของชั้นนั้น (สูตรค้างเดิม: ถือ × max(0, ทุนเฉลี่ยชั้น − SL ชั้น))
4. **ช่อง `Risk %` ทุกไม้** (แทนช่องเลือก FF ในฟอร์ม — FF ใช้ค่าจริง แสดงเป็นคำอธิบาย): ค่าเริ่ม ไม้แรก = ค่าตั้ง **Risk ไม้แรก** (0.6%) · เติม Base = **ครึ่งหนึ่งของ Risk ไม้ก่อน** · ไม้เร่ง = งบเร่งที่เหลือ · ใส่น้อยกว่าได้ · **ใส่เกินงบที่เหลือไม่ได้** (บรรทัดใต้ช่อง `Risk ใส่ได้ถึง x% (…)` · งบเต็ม → `งบ Base เต็ม → ยก SL Base ก่อน`)
5. **ขนาด** = Risk ไม้นี้ ÷ (Entry − SL ของชั้น) แล้วติด: เพดานไม้แรกตาม Tier (เฉพาะไม้แรก · เดิม) · **เพดานเงินต่อหุ้นรวมทุกไม้** (`capTotalA/B` · ค่าเริ่มใหม่ **15** · ตั้งได้ ≤ **25**) · เงินสด · ปัดล็อตเดิม
6. **กฎ "ไม้เติม ≤ 50% ของไม้ก่อน" → เตือน ไม่บล็อก** (`⚠ เกิน 50% ของไม้ก่อน (n หุ้น) — บันทึกได้`) · **ไม้เร่งไม่เตือน**
7. **ไม่บังคับยก SL Base ก่อนเข้าไม้เร่ง** (ผู้ใช้เข้าตอน break กรอบ)
7b. **จำนวนไม้สูงสุด (`maxLots`) นับเฉพาะไม้ Base** (ป้าย `#n/N` = Base) · ไม้เร่งไม่นับ — ไม้เร่งมีได้ 1 ชั้น (เติมเข้าชั้นเร่งได้หลายครั้ง ใช้ SL เร่งร่วมกัน) คุมด้วยงบเร่ง + เพดานต่อหุ้น + เงินสด · ค่าตั้งเปลี่ยนป้ายเป็น `ไม้ Base สูงสุด`
8. **ออก:** ปิดสัปดาห์ใต้ SL เร่ง = **ขายเฉพาะไม้เร่ง** (ปิดบางส่วน · Base ถือต่อด้วย SL เดิม ไม่มีเตือนเพิ่ม) · ใต้ SL Base = ขายหมด (เดิม) · Stop ฉุกเฉินคิดแยกต่อชั้น (SL ชั้น × (1 − %))
9. **เลื่อน Stop** เลือก `Base | เร่ง | ทั้งคู่` · ขึ้นอย่างเดียว (เดิม) · stopHistory บันทึกชั้น
10. **Risk Core / ชั้น 2 / บัญชีลด** = รวมทุกชั้นตาม SL ของชั้น (สูตรเดิมต่อชั้น)
11. **Journal:** ไม้เร่งที่ออกเป็นการปิดบางส่วนของไม้เดิม · R คิดจาก SL เร่งตอนเข้า · มีป้าย `เร่ง` + ชิปตัวกรอง `ไม้เร่ง` · สถิติตาม Setup ไม่เปลี่ยน
- **ข้อมูล:** `lots[].layer` = `'base' | 'acc'` (ไม่มี = base) · `stopAcc` (SL เร่งปัจจุบัน) · `stopHistory[].layer` · `lots[].risk` (Risk % ที่ผู้ใช้ใส่) · การ์ดเดิมไม่ต้องย้ายข้อมูล (ไม่มี layer = Base ทั้งหมด · ทำงานเท่าเดิม)
- **core-size.js:** `addLot` รับ `riskPct` ของไม้นี้ + `layer` (acc = ไม่ใช้ target 50% · base = ใช้ target แค่ทำป้ายเตือน `over_ratio`) · `layer2` รับ positions แยกชั้นได้ · ฟังก์ชันเดิมเรียกแบบเดิมต้องได้ผลเดิมทุกตัว

## 2. การ์ด Core แบบตัวเลขน้อย — `ln3fix2-core-mockup.html`
- **กล่องสรุป:** `Core · ทุน ฿x` · ปุ่มบัญชี · `Risk Core x% / 20%` + บรรทัด `เงินว่าง ฿ · DD · FF` · ฿ / ถ้า Ladder เต็ม / Winners ถือ / Ladder % → พับ `รายละเอียดและกฎ` · แถบเตือนเฉพาะเมื่อมี
- **แถวการ์ด:** `ไม้ n · SL 115 · เร่ง 140` (ไม่มีไม้เร่ง = ไม่มีคำว่าเร่ง)
- **กาง:** `ราคา · EMA10` · `ขนาด · เสี่ยง` (ขนาด % เทียบเพดานต่อหุ้น · "(เต็ม)" เมื่อถึง) · กล่อง 2 แถว `Base n @ทุน SL x` / `เร่ง n @ทุน SL y` · ปุ่ม อัปเดตราคา · เติมไม้ · เลื่อน Stop · ⋯
- **⋯ =** ปิด/ขาย · แก้ · ยกเลิก · ลบ · **ดูไม้ที่ซื้อ** (รายไม้ + Risk ที่ใส่) · ประวัติ Stop · **Stop ฉุกเฉิน** · Tier/Watchlist เป็นป้ายเตือนเฉพาะเมื่อมีปัญหา · งบที่ใช้ไปโชว์เมื่อ ≥ 80%
- **หน้าต่างเติมไม้:** `☐ ไม้เร่ง (SL แยก · งบแยก)` · แถวเดียว `Entry · SL (Base/เร่ง) · Risk %` · บรรทัดใส่ได้ถึง · ผลบรรทัดเดียว `n หุ้น · เสี่ยง $x ✅` · เหตุผลเฉพาะเมื่อติดเพดาน/เกินงบ/เตือน 50% · ยกเลิก + บันทึกไม้
- **ฟอร์มแผนใหม่:** แถว `Entry · Stop · Risk %` (ค่าเริ่ม Risk ไม้แรก) · Tier บรรทัดเดียว `Tier A · Fortress · เพดาน x%` · ตัวเลข Tier **พับเมื่อมี Tier แล้ว** · บรรทัดอธิบาย Ladder โผล่เฉพาะเมื่อกด Ladder ไม่ได้

## 3. ตั้งค่า › Core — `ln3fix2-settings-mockup.html`
- `งบเสี่ยง Base ต่อหุ้น %` (= riskA/riskB เดิม · ป้ายใหม่) · **`Risk ไม้แรก (ค่าเริ่มในฟอร์ม) %`** ใหม่ (0.6 · ≤ งบ Base) · `เตือนเมื่อเติม Base > % ของไม้ก่อน` (= addRatio เดิม) · `ไม้ Base สูงสุด` (= maxLots · ไม่นับไม้เร่ง) · **`งบเสี่ยงไม้เร่ง %`** ใหม่ (0.35) · `เพดานเงินต่อหุ้น (รวมทุกไม้) %` (= capTotal · ค่าเริ่ม 15 · รับ 1–25) · หัวหมวดสรุป `Base x% (ไม้แรก y) · เร่ง z% · ต่อหุ้น ≤ w%`
- **ค่าที่ผู้ใช้บันทึกไว้แล้วห้ามเปลี่ยน** (เปลี่ยนเฉพาะค่าเริ่มของช่องที่ยังไม่เคยตั้ง)
- ถ้าเพดานไม้แรก > เพดานต่อหุ้น → บรรทัดเตือนใต้ช่อง (ไม่บล็อก)

## 4. แผน Sat — "แผน & ไม้ที่ถือ" — `ln3fix2-plan-mockup.html`
- **ตัดส่วน Positions + บรรทัด heat ท้ายหน้าแผน Sat (Lean)** — ข้อมูลไปอยู่ในการ์ด "แผน & ไม้ที่ถือ" (หัว `ถือ n · แผน m`)
- แถวที่เข้าแล้ว: **กางเป็นค่าเริ่ม** · แตะหัวแถวพับ/กาง (พับ = บรรทัดสรุป `● lot $ · ● lot $ · รวม $/$cap`) · กาง = `รวม $/$cap` + ต่อบัญชี 2 บรรทัด `● บัญชี lot · n วัน   $เสี่ยง ⋯` / `ทุน · SL · TP` · ⋯ = ปิด · แก้ · ยกเลิก · ลบ (ฟังก์ชันเดิมของ Positions)
- **ไม้นอกแผน** = แถวของตัวเองป้ายแดง `นอกแผน` (`ทุน · SL`) กางได้เหมือนกัน · ผูกกับแผนผ่าน ⋯ ถ้ามีฟังก์ชันเดิม (ไม่มี = ไม่ต้องทำ)
- เรียง: ถืออยู่ → รอเข้า → ร่าง → รูปแบบเดิม (พับ) · แตะแถว → Strategy ตาม Asset (LN3fix) ยังทำงาน
