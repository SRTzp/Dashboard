## 2. เพดาน 2 แถว/วัน (นอกด่วน)
- รวม B + C + D แล้ว **เอาแค่ 2 แถวแรก** เรียง: B → C → D (ภายในกลุ่ม: B ตามวันที่ไอเดีย · C ตาม rank แล้ว sym · D ตามข้อ 1)
- A (ด่วน) ไม่นับในเพดาน · ไม่จำกัดจำนวน (แต่ 1 แถวต่อไอเดีย)
- ที่ถูกตัดเพราะเพดาน: ไม่แสดง · ไม่มีข้อความ "อีก n"
