How it works
① Level + direction on every idea (stock, market, Sat, tag). Default direction: none → asks once.
② / ③ Price source (display only, never feeds sizing): stock = last daily close (existing feed) · anything else = the last price you typed. Older than 24 h → amber “old price”.
Level hit = price ≥ / ≤ level on that price or you press Level hit after the TradingView alert arrives (dashboard cannot see TradingView). Stored once with the time; leaves when reviewed, snoozed or planned.
④ level set + no TV alert → amber “not set” (a to-do) · Copy puts the plain number on the clipboard (TradingView cannot be pre-filled).
⑦ on Save idea (new, or level changed, level set, TV alert not ticked) the alert text TAG ≤ level · Title is copied automatically and the toast says so — paste it as the TradingView alert name / message · edits that don’t touch the level never touch the clipboard.
⑤ the one dark button = the action once hit: Make plan › (stock) / Open › (others) · ⑥ quiet link.
Today row: amber pill level hit (ranks first) · the old “within 3%” blue pill stays for stocks only (2.1% to level, blue = distance).
Notifications: the app can only alert while it is open (browser notification, like the 20:00 reminder). The real-time push comes from TradingView on your phone.
