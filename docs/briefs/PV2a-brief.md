## 2. โครงพอร์ต: Core 70 / Satellite 30 (แทน Core / Sat / Option 70/20/10)
- หน้า Port + ทุกจุดที่คิดเงิน Sat: เงิน Satellite = 30% ของบัญชี · Main = Satellite × 70% · Tactical = Satellite × 30% (ตามตั้งค่า)
- Port Option หายจากการแบ่งเงิน · ข้อมูล/ไม้เดิมที่เป็น Option (ถ้ามี) **ไม่ลบ** — แสดงในส่วน "อื่น ๆ (เดิม)" อ่านอย่างเดียว · รายงานว่าพบกี่รายการ
- แถบ Port ตามม็อกอัป ① (Core 70 · Main 21 · T 9 + เงินแต่ละส่วน)

## 3. ฟอร์มแผน Sat ใหม่ (ม็อกอัป ④)
- ปุ่ม `Main | Tactical` (ค่าเริ่ม Main) · **Tactical สร้างได้เฉพาะ Asset ที่เลือกสัปดาห์นี้** (ไม่ได้เลือก → ปุ่มปิด + เหตุผล)
- ช่อง: **TF** (ข้อความ · เติมค่าเริ่มตามส่วน) · **Setup** (ป้ายจากรายการของส่วนนั้น · เลือกได้หลายอัน) · **เสริม** (ข้อความ ≤ 60 ตัว เช่น `Break Point 4,245`) · **ทิศ** · **Entry** · **SL**
- **ตัดช่อง Break Price / Break Vol / Pullback / Vol ในแผนใหม่** · ปุ่ม TF 4H/D/W เดิม → แทนด้วยช่อง TF ข้อความ
- TP: Tactical คิดให้จากตั้งค่า (TP1 2R 50% · TP2 3R) แสดงราคา · Main กรอก TP เองได้ (ไม่บังคับ) + Trend Shift เดิม
- ขนาดไม้ (แสดงตารางเหมือนม็อกอัป): Risk$ = เงินส่วนนั้น × RPT × ตัวคูณ Macro (WA1 เดิม) · lot ตาม Risk = Risk$ ÷ (|Entry−SL| × ขนาดสัญญาของสินค้า) · เพดานมูลค่า = เงินส่วนนั้น × เพดาน ÷ (Entry × ขนาดสัญญา) · ใช้ค่าน้อยสุด ปัดลงตาม lot step ของโบรก · บอกว่า **ตัวไหนจำกัด** + Risk จริง
- Main: การเติมไม้ 50/30/20 (PY2) ใช้ต่อ อยู่ใน Risk ของ Main · Tactical: ไม่มีเติมไม้
- ไม้ที่บันทึกเก็บ `sleeve` (`main`/`tactical`) · `setups[]` · `setup_note` · `tf` · `size_limit` (ตัวที่จำกัด)

## 4. ของเดิม (ห้ามหาย)
- แผน/ไม้ที่มีอยู่ทั้งหมด = `sleeve:'main'` อัตโนมัติ (ไม่ต้องกรอกใหม่)
- แผนเดิมที่มีเงื่อนไข Break/Pullback (kind `bp`) → **ยังแสดง/แก้/Activate แบบเดิมได้จนปิด** · ไม่แปลงข้อมูล · แผนที่สร้างใหม่ใช้ฟอร์มใหม่เท่านั้น
- Macro · เลือก Asset สัปดาห์ · Bias · ยกแผนข้ามสัปดาห์ · ไอเดียเทรด `＋ วางแผน` (TR1 → เปิดฟอร์มใหม่ เลือก Main/Tactical ได้) ทำงานเหมือนเดิม
