## ข้อตัดสิน
- ตอนนี้แผน Sat ผูกสัปดาห์ (`idea.week`) → ขึ้นสัปดาห์ใหม่ แผนที่ยังไม่เข้าหายไปจากหน้า Strategy
- ใหม่: แผนของสัปดาห์ก่อนที่ **ยังไม่มีไม้เปิด และยังไม่ปิด/ยกเลิก** (draft หรือ planned · ไม่ว่าเงื่อนไขจะ active หรือไม่) → ขึ้นในสัปดาห์ปัจจุบันพร้อมป้าย `ยกมาจาก <สัปดาห์> · เช็ก Bias ใหม่`
  - ก่อนกดยืนยัน: **ห้ามบันทึก order / ห้าม Activate** (เงื่อนไขที่เคย active → แสดงเป็นรอ ไม่ลบค่า) · แก้ค่าได้
  - ปุ่ม `ใช้ต่อสัปดาห์นี้` → `idea.week = สัปดาห์ปัจจุบัน` · เก็บ `carried_from:[…สัปดาห์เดิม]` · เงื่อนไขที่ครบอยู่แล้ว Activate ตามกติกา AC2 อีกครั้ง
  - ปุ่ม `ไม่ใช้` → ปิดแผนแบบเดิม (เหมือนปิดแผน · ไปอยู่ประวัติ `unused`)
  - Bias สัปดาห์ใหม่ยังไม่ทำ → ปุ่ม `ใช้ต่อ` ปิด + `ทำ Bias สัปดาห์นี้ก่อน` · Bias ใหม่สวนทิศแผน → ยืนยันได้แต่ถูกบล็อกตามกติกา SR1 เดิม (ห้ามสวน Bias) + ป้ายแดง `สวน Bias สัปดาห์นี้`
  - ยกได้ทุกสัปดาห์ (ต้องกดยืนยันทุกครั้ง) · ไม่จำกัดจำนวนครั้ง
- **แผนที่มีไม้เปิดอยู่** (รวมไม้ PY2 ไม้ 2/3): แสดงในสัปดาห์ปัจจุบันเสมอ (ไม่ต้องยืนยัน) · จัดการไม้ได้ครบ (เติมไม้ · เลื่อน SL · ปิด) — ตรวจว่าตอนนี้แสดงอยู่จริงหรือไม่ ถ้าหายไปเมื่อขึ้นสัปดาห์ใหม่ให้แก้ + รายงาน
- ข้อมูลระดับสัปดาห์ (แนวรับ/ต้าน · Trend Shift · กราฟ VW1) ของแผนที่ยกมา = ของ **สัปดาห์ปัจจุบัน** (แสดงว่างถ้ายังไม่กรอก)
- **Asset ของแผนที่ยกมา → ใส่ใน `satWeekPick` สัปดาห์ใหม่ให้อัตโนมัติ** (WA1 · ถ้ายังไม่ครบ 3) · เกิน 3 → การ์ดยกมาอยู่แถบ `ไม้ค้าง · ไม่ได้เลือกสัปดาห์นี้` พร้อมปุ่มยืนยัน/ไม่ใช้ (ยืนยันได้เมื่อเพิ่ม Asset เข้าสัปดาห์นี้ก่อน) · กด `ไม่ใช้` → เอา Asset ออกจาก pick ถ้าไม่มีแผน/ไม้อื่น
- Asset ที่มีไม้เปิดแต่ผู้ใช้ไม่ได้เลือกสัปดาห์นี้ → แถบไม้ค้าง ตาม WA1
- โควตาไม้ใหม่/สัปดาห์ นับตามสัปดาห์ที่เปิดไม้จริง (เดิม · ไม่เปลี่ยน)
