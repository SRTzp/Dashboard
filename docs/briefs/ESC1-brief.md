## 1. Esc ปิด pop-up ทุกตัว (ข้อ 1–3 ของผู้ใช้)
- ตอนนี้ Esc ปิดได้แค่ `.overlay.show` · `.scorePop` · lightbox กราฟ (`#vwLb`) · เมนู `.ccMenu` · กล่องคำศัพท์ · บางตัวในแท็บ Watch
- **ยังปิดไม่ได้** (สำรวจเพิ่มเองให้ครบ แล้วรายงานรายการ): sheet ของการ์ด Core (`coreSheet` → `.core-sheet` เช่น แผนใหม่ / ซื้อไม้ 1 / Tier / อัปเดตราคา / เลื่อน Stop) · sheet ใน Sat (ตัวแก้ setup ฯลฯ) · เมนู phase (PH1) · แผง Filter (UX2) · sheet กรอกค่าพอร์ต (GL1) · Import / จับคู่ list · ตัวยืนยันที่เป็น sheet ของแอป
- ทำ **ตัวจัดการ Esc ตัวเดียว** (ต่อจากตัวเดิมที่ ~บรรทัด 12960): ปิด **ชั้นบนสุดชั้นเดียว** ต่อการกด 1 ครั้ง ลำดับ: lightbox กราฟ → กล่องคำศัพท์ / popover / เมนูลอย (`.ccMenu` · phase · Filter) → sheet (`.core-sheet` · sheet อื่น) → `.overlay.show` · ปิดผ่านฟังก์ชันปิดเดิมของแต่ละตัว (เช่น `coreSheetClose()` · `vwLbClose()`) ไม่ลบ DOM เอง
  - กด Esc ขณะพิมพ์ในช่องของ sheet → ปิด sheet ได้ (เหมือน `.overlay` เดิม) · ยกเว้นกำลังพิมพ์ผ่าน IME (`isComposing`) · ข้อมูลที่ยังไม่บันทึกไม่ต้องถาม (เหมือนกดปิด/ยกเลิก)
  - ไม่มีอะไรเปิด → Esc ทำงานแบบเดิม (เช่น Watch กลับรายการบนมือถือ)
- lightbox กราฟ: ตรวจว่า Esc ปิดได้จริงตอนเปิดจากการ์ด Sat และจาก แท็บ มุมมอง (ผู้ใช้บอกว่าปิดไม่ได้ — ถ้าเจอสาเหตุ (เช่น listener อื่นดัก / focus) แก้และรายงาน)

## 2. กราฟเห็นเต็ม ไม่ครอป (ข้อ 1)
- ตอนนี้ `.vwImg img{object-fit:cover}` + ความสูงตายตัว → กราฟ TV (มักกว้าง ~2:1 และบางภาพมีหลายกราฟเคียงกัน) ถูกตัดบน/ล่าง/ข้าง
- แก้: การ์ด Sat (`vwSat`) และภาพใน แท็บ มุมมอง แสดง **ทั้งภาพ** = กว้างเต็มช่อง · สูงตามสัดส่วนภาพ (`height:auto` · `object-fit:contain` · ไม่กำหนดความสูงตายตัว) · ป้ายวันที่/ปุ่ม `เปลี่ยน` ยังวางทับมุมได้
- รูปจิ๋วในแถว (`vwMini` 54×30) คงแบบเดิม (ครอปได้ เป็นแค่สัญลักษณ์)
- แตะภาพ → lightbox เต็มจอเหมือนเดิม

## 3. ปุ่มทิศ Break อันเดียว (ข้อ 4)
- ตอนนี้แถว Break Price กับ Break Vol มีปุ่ม ▲▼ แยกกัน → เปลี่ยนเป็น **ปุ่มเดียว** (วางที่แถว Break Price · แถว Break Vol แสดงลูกศรเดียวกันแบบอ่านอย่างเดียว ไม่ใช่ปุ่ม) · แตะ = สลับทั้ง `brk_dir` และ `vol_dir` พร้อมกัน (เขียนค่าเดียวกันทั้งคู่)
- ข้อมูลเก่าที่ `brk_dir` ≠ `vol_dir` → แสดงตาม `brk_dir` · แตะครั้งแรกเขียนทั้งคู่ให้ตรงกัน
- ค่าเริ่มตามทิศเงื่อนไขเหมือนเดิม · สี ▲ เขียว ▼ แดงเหมือนเดิม · บรรทัดสรุป Active ใช้ทิศเดียวกันทั้ง 2 ส่วน

## 4. แท็บ มุมมอง: ช่องกราฟ TV เห็นทันที + กราฟเต็มในแท็บ (ข้อ 5)
- ตอนนี้ช่องลิงก์กราฟซ่อนอยู่ใน Tech (ต้องแตะแถว Tech ก่อน) → ผู้ใช้ไม่เห็น
- แถว Tech (ตอนพับ): ถ้ายังไม่มีกราฟ → แสดงปุ่มเล็ก `＋ กราฟ TV` ท้ายแถว (แตะ = กาง Tech + โฟกัสช่องลิงก์) · มีกราฟแล้ว → รูปจิ๋วเดิม
- แถว Tech (ตอนกาง): **กราฟล่าสุดแสดงเต็มกว้างทั้งภาพบนสุดของส่วน Tech** (ตามข้อ 2 · ไม่ต้องแตะเพื่อดู) แล้วตามด้วยประวัติ + ช่องบันทึก/ลิงก์เดิม · แตะแถว Tech อีกครั้ง = พับ (toggle เดิม)
- ใช้ที่เก็บเดิม (`stockNotes/{SYM}.tech[].chart`) · ใช้ร่วม Watchlist + Candidates (แถวขยาย Candidate ก็มีปุ่ม `＋ กราฟ TV` แบบเดียวกัน) · ไม่มี rule ใหม่
- กราฟในประวัติ Tech ข้อเก่า ๆ ยังเป็นภาพย่อ (แตะ = lightbox)
