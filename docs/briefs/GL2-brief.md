## ข้อตัดสิน (ผู้ใช้ 9 ต.ค.)
- ค่าพอร์ต (GL1 `goalLog`) กับทุนในตั้งค่า (`settings.capital` ต่อบัญชี) **ยังแยกกัน** · แอปไม่แก้ทุนให้เอง — แค่เตือน
- เตือนเมื่อ |ต่าง| > 10% · รอบกรอกยังเป็นรายสัปดาห์ (ไม่เปลี่ยน GL1)

## 1. ทุนที่ใช้เทียบ (ต่อบัญชี)
- `ทุนแอป` = ค่า `cap` จาก `mixAcctStats(entry)` ของบัญชีนั้น (ฐาน THB · = ทุนทุกพอร์ตที่บัญชีเปิดใช้ + strategicCash) — ใช้ฟังก์ชันเดิม ห้ามเขียนสูตรใหม่
- แปลงเป็นสกุลของเป้า: เป้า USD → `cap / fx` (fx ของบัญชีนั้น `state.settings.fx` ผ่าน `withState`) · เป้า THB → `cap`
- `ต่าง = ค่าที่กรอก / ทุนแอป − 1` · ทุนแอป ≤ 0 → ไม่แสดงบรรทัดเทียบ

## 2. ใน sheet
- ใต้ช่องของแต่ละบัญชี บรรทัดเล็ก 1 บรรทัด (อัปเดตทันทีขณะพิมพ์ · ช่องว่าง = ไม่แสดง):
  - |ต่าง| ≤ 10% → สีจาง: `ทุนในตั้งค่า $140.0k (ต่าง +3.6%)`
  - |ต่าง| > 10% → สี amber: `ทุนในตั้งค่า $120.0k · ต่าง +20.8% → พิจารณาปรับทุนใน ตั้งค่า` (คำ "ตั้งค่า" กดแล้วเปิดตั้งค่าระบบส่วนทุน · ไม่บันทึกค่าที่ยังไม่กด บันทึก — ถ้ามีค่าค้างให้ถามก่อน)
- รูปเงินใช้ `glMoney` · % ทศนิยม 1 · ไม่ตัดบรรทัดที่ 390px (ยาวเกินให้ `…`)
- ไม่บล็อกการบันทึก · หลังบันทึก ไม่ต้องเตือนซ้ำที่การ์ดเป้า
- แก้เพิ่ม (ค้างจาก GL1): placeholder + ข้อความใต้ช่องใน sheet ใช้ฟอนต์ปกติ (ไม่ใช่ mono)
