## PB1b rev 3.1 — Sat plan popup · Trend rule · Place-order confirm · Strategy → Flow

Spec: `docs/briefs/PB1b-brief.md` (rev 3.1) + `docs/briefs/mockups/pb1b-sat-popup.html`. Branch `claude/pb1` (on top of PB1). **Not merged.**

### What changed
- **New-plan popup = 3 steps on any tab** (no tab switch): `S / D / F` → asset `1…n` (★ this week's focus first; an asset with a Planned plan shows "plan exists → edit") → the Sat form in the same popup (Mac centred 460 px, iPhone bottom sheet). `‹` / Esc = back one step, ✕ / dim = close, Save → stays on the tab + toast `Plan saved · View in Plan ›`. Board "Edit" / "Complete ›" / drawer "Update levels" / Today "Create plan ›" open the same form (`td3SatOpen` → `pb2OpenEdit`).
- **Sat form** (one column): Buy|Sell · Main|Family → Entry · SL · TP → TREND (EMA50, Structure) → [MSS question] → size box (label + lot · risk $ at SL · R:R) → [amber warning] → grey Setup reminder → macro line → Save draft · Save plan. EMA50 / Structure start **unselected**, tap again unselects. Small `hold · all ✓` pill (0.8 s, tap does nothing; mouse / touch / keyboard Space·Enter) sets both ✓. Side check (Buy SL < Entry < TP · Sell SL > Entry > TP) and R:R ≥ 1.5 keep a plan 🕓 Waiting. No Setup checkboxes / Range / MSS price field.
- **Trend rule (§3)** in `ln4VerifyOf` (one place, used by size, card, drawer, Journal tag): ✓✓ 100 % · EMA ✗/Str ✓ 60 % + nearest-target warning · EMA ✓/Str ✗ → MSS question (Yes = *Counter trend @ MSS* 60 %, No/blank = Blocked) · ✗✗ → MSS question (Yes = *Reversal @ MSS* 60 % + warning, No/blank = Blocked). One 60 % factor (`SAT_RED_FAC`), never stacked. MSS question starts with nothing selected; flipping Structure to ✓ clears the answer. The old counter-trend confirm at Save is kept for EMA ✓ / Str ✗.
- **Place order = one-tap confirm** `Setup ready on Execution TF?` (+ `MSS confirmed per your rules (candle closed)` for MSS trades), `[Not yet] [Yes · mark ordered]` (Enter = Yes, Esc = Not yet). Yes → existing Ordered state + **snapshot** `ln4.snap['0'] = {t, entry, sl, tp, dir, acct, ema, structure, mss, label, mult, lot, riskPct, riskAmt, macro, setupOk:true}` written once with the order; plan edits never touch it. Cancel order removes the order and its snapshot. Blocked plans: pill disabled, tooltip `Blocked by trend rule`. Core Place order keeps the existing confirm.
- **States (§3b)**: 🕓 Waiting = missing/invalid Entry·SL·TP, wrong side, R:R < 1.5, Trend not fully chosen (`needs MSS answer` when only that is missing); 📝 Planned (+ red `Blocked` tag, no Place order); card tags `Counter trend @ MSS` / `Reversal @ MSS` and a ⚠️ icon for the two warned cases. Drawer CHECKS shows Trend/MSS result (no Setup row). Journal tag + closed-trade "Order snapshot" line.
- **Strategy → Flow**: Plan no longer has the Sat Strategy page, `Sat assets ›` link or `‹ Plan board` bar (the legacy panel stays hidden in the DOM). Top of Flow = **🌐 Macro · this week's Sat focus** (week selector, regime, one chip per asset with macro bias; tap = ★ focus this week via the existing `satWeekPick`; `＋ Asset` = existing add-asset sheet), then Weekly Impact, then Fund flow / RRG. "Go to Strategy" links now go to Flow.
- **PB1 §2c finish**: Holding card whose next unfilled level is Planned and < 2 % away → `Place order ›` (that level); `% to entry` = nearest *unfilled* level in every card state.

### Decisions / deviations (please check)
- **Mockup note still says "rev 3"** (brief says rev 3.1; the rules in the mockup match 3.1). Committed as given.
- **No "reduced multiplier" Settings key exists** — 60 % was hard-coded in `ln4VerifyOf`; it is now one constant `SAT_RED_FAC = 0.6`, not a Settings field.
- **Trade slot timing**: *Save plan* stores the idea only (no broker trade). The trade (`status:'plan'`) is created at **Filled ✓** through the existing `satV3SaveSlot` (all existing sizing blocks apply) and then marked open with the existing price prompt; the order snapshot is copied to the trade (`orderSnap`) for the Journal. A fill that the sizing code refuses (news window, loss limit…) shows the reason and opens the form.
- **Plans on an asset that is not this week's ★** no longer vanish from the board (extra rows from `satIdeasList`); saving a plan on such an asset also ★-focuses it while there are < 3 picks.
- **Sat has no TV1 section** in the app (TV1 lists stocks only), so "TV1 Sat `###READY - SETUP`" has nothing to change; Core TV1 output is untouched (suite 368 ✓).
- **Per-asset Strategy tile content** (Quarterly Macro text, "Note · This week", Weekly-Impact strip inside the tile) lived on the removed page; it is not visible anywhere now. Phase 100's tile checks run against the hidden panel through the DOM.
- The Main|Family switch picks the account (`pb_acct` on the idea); it is hidden when only one Sat account exists.
- Tactical sleeve ideas still open the same form (sleeve is kept) but the form has no Tactical controls.
