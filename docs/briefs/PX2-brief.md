# PX2 — ราคา auto เติมช่องที่กรอกเองเว้นว่าง · ปุ่มใช้ราคาอัตโนมัติ · พับ/ลบการ์ดที่ปิดแล้ว · (+ ทิศ ▲▼ ในผลจับคู่ list) · เทส 48

> ต่อจาก ID3a (ต้องจบ ID3a ก่อน) · ที่มา: ผู้ใช้ใช้จริง 5 ต.ค. — การ์ด AVGO กรอกเอง 350 (ศ. 2 ต.ค. · ไม่ได้ใส่ EMA) วันเดียวกับ auto 355.14 / EMA 367.06 → ตามกติกา PX1 "วันเท่ากัน = กรอกเองชนะทั้งชุด" การ์ดเลยได้ 350 + EMA ว่าง ทั้งที่ auto มี EMA · การ์ด AAPL "ปิดแล้ว · ลบไม้" ค้างในหน้า ไม่มีทางเอาออก
> ผู้ใช้ตัดสิน 5 ต.ค.: (1) เติมช่องว่างจาก auto + ปุ่มใช้ auto (2) การ์ดปิดแล้วพับรวม + ปุ่มลบต่อตัว
> สำรองก่อนแก้: `index.backup-pre-PX2.html` · `tests/_bk_px2/` · ห้ามแตะ core-size.js · ห้ามแตะ `P2-prices-upload/` · ห้ามย้อนงานรอบก่อน

## 1. EMA ว่างในค่าที่กรอกเอง → ใช้ EMA ของ auto วันเดียวกัน (`coreApplyPx`)
- กติกาเลือกราคาเดิมไม่เปลี่ยน (auto ใช้เมื่อ ไม่ suspect · close > 0 · closeDate ใหม่กว่า pxDate หรือไม่มี pxDate)
- เพิ่ม: กรณีใช้ค่าที่กรอกเอง (`pxSrc:'manual'`) **และ** การ์ด W (ไม่ใช่ L) **และ** `emaW` ว่าง/≤0 **และ** มี auto ที่ไม่ suspect · `ema10w > 0` · `closeDate === pxDate` → `emaW = auto.ema10w` + ธง `emaSrc:'auto'` (ค่า px ยังเป็นที่กรอกเอง)
- auto วันอื่น (เก่ากว่า) → ไม่เติม (กัน EMA คนละสัปดาห์)
- หน้าการ์ด: ช่อง ราคาปิด · EMA10 แสดง EMA ที่เติม · บรรทัดล่างแทน "ยังไม่กรอก EMA10" ด้วย `EMA10 อัตโนมัติ` · สถานะ/ปิดใต้ EMA/DD ใช้ค่าที่เติมนี้ตามปกติ
- ค่าที่เติมเป็นค่าแสดงผลเท่านั้น — **ห้ามเขียนลง coreCards** (เหมือน PX1: action ใด ๆ ส่งเฉพาะ patch ของตัวเอง)

## 2. sheet อัปเดตราคา: ปุ่ม `ใช้ราคาอัตโนมัติแทน`
- แสดงเมื่อ: การ์ดใช้ค่าที่กรอกเอง (`pxSrc:'manual'`) และมี auto ที่ไม่ suspect · close > 0 · ไม่แสดงเมื่อการ์ดใช้ auto อยู่แล้ว / ไม่มี auto / auto suspect
- ตำแหน่ง: ใต้บรรทัด "ราคาอัตโนมัติล่าสุด: …" (ปุ่มรอง ไม่ใช่ปุ่มหลัก)
- กด → ยืนยันในตัว sheet (ไม่ใช้ confirm()): `ลบราคาที่กรอกเอง ({px} · {วันที่}) แล้วใช้ราคาอัตโนมัติ {close} · EMA10 {ema} ({วันที่ auto})` → ตกลง → `coreWrite(id, {px:null, pxDate:null, emaW:null})` → การ์ดใช้ auto ทันที (ป้าย อัตโนมัติ)
- ข้อความเตือนในหน้ายืนยัน 1 บรรทัด: `ถ้าราคาอัตโนมัติหยุดอัปเดต การ์ดนี้จะขาดราคาจนกว่าจะกรอกใหม่`

## 3. การ์ดที่ปิดแล้ว: พับรวม + ลบต่อตัว (`coreClosedHtml` / `coreAcctHtml`)
- ทุกการ์ด `kind==='closed'` ของบัญชี รวมเป็น `<details>` เดียวท้ายรายการ: หัว `ปิดแล้ว {n} ตัว` (พับไว้เป็นค่าเริ่ม) · n = 0 → ไม่แสดง
- ข้างใน 1 แถวต่อการ์ด: `{SYM} · {ปิดตำแหน่ง/ยกเลิกไม้/ลบไม้} · {ไม้ … (บรรทัดเดิม)}` + ปุ่ม `ลบการ์ด`
- กด `ลบการ์ด` → sheet ยืนยัน: `ลบการ์ด {SYM} ที่ปิดแล้ว — ไม้ใน Journal ยังอยู่ครบ สถิติไม่เปลี่ยน · ประวัติไม้/Stop ในการ์ดจะหาย` → ตกลง → `coreDelete(id)`
- ลบได้เฉพาะ `kind==='closed'` (plan มี "ลบแผน" เดิม · open ต้องปิด/ยกเลิกไม้ก่อน) — กันที่ฟังก์ชันด้วย ไม่ใช่แค่ซ่อนปุ่ม
- ตรวจ: ไม้ที่ซื้อผ่านการ์ดมี `unplanned:false` อยู่แล้ว → ลบการ์ดปิดแล้วต้องไม่ทำให้ไม้นั้นกลายเป็น "ไม้นอกแผน" (`tradeOffPlan`) และสถิติ Journal / Win Rate / setup stats ไม่เปลี่ยน — ถ้าเจอจุดที่เปลี่ยน ให้หยุดและรายงาน ห้ามแก้เอง
