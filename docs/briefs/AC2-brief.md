- **ติ๊กแล้ว = กลายเป็นบรรทัดสรุป** (แตะบรรทัดสรุป = กลับเป็นแถวกรอกของข้อนั้น · ติ๊กยังอยู่ · แก้ตัวเลขได้):

## 1. ที่เก็บ (ในเงื่อนไขเดิมของ `satIdeas` · ไม่ต้องเพิ่ม rule)
- `conditions[i]` เพิ่ม: `brk_px:number|null` · `brk_dir:'up'|'dn'|null` · `vol_px:number|null` · `vol_dir:'up'|'dn'|null` (null = ใช้ค่าเริ่มตามทิศ)
- คงเดิม: `kind:'bp'` · `steps{brk,vol,pb}` · `brk_tf` · `pb_from` · `pb_to` · `tp_from` · `tp_to` · `inval` · `active`
- **ค่า Pullback ที่ใช้จริง** `satAcZone(c)`: มี `pb_from`/`pb_to` → ใช้ตามเดิม · ไม่มี และมีทั้ง `brk_px` กับ `vol_px` → `{from:min, to:max}` (ถ้าเท่ากัน = ค่าเดียว) · ไม่มีทั้งหมด → null
- **แก้ AC1 ข้อกังวล (แผนเก่าหลุด):** เงื่อนไขเก่าที่ `active:true` และไม่มี `steps` → ตอนแปลงใน `satAcWrite` ใส่ `legacy_ok:true` · `satAcMissing` ของข้อที่ `legacy_ok` ไม่นับ Break Price / Break Vol / Pullback ที่ไม่มีตัวเลข (นับแค่ติ๊ก + TP + Inval) → แก้ TF / กรอกตัวเลขเพิ่มแล้ว**ต้องไม่หลุด Active** · เอาติ๊กออก / ลบ TP / ลบ Inval → หลุดตามปกติ

## 2. ฟังก์ชัน (ต่อยอด AC1 · ใช้ `satAcWrite` → `satAcSync` → `satV3CondActivate` เดิม)
- `satAcSetLevel(ideaId, condId, key, val)` key = `brk_px`|`vol_px` · > 0 เท่านั้น · ลบค่า (ว่าง) ของข้อที่ติ๊กอยู่ → เอาติ๊กข้อนั้นออกด้วย
