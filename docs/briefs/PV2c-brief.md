## 1. แบ่งไม้ตั้งค่าได้ต่อส่วน (ตั้งค่า › Sat v2 · ต่อบัญชี)
| ค่า | ค่าเริ่ม | รูปแบบ |
|---|---|---|
| แบ่งไม้ Main | `50/30/20` (3 ไม้) | ข้อความ % คั่นด้วย `/` · 1–4 ไม้ · แต่ละไม้ > 0 · รวม = 100 |
| แบ่งไม้ Tactical | `100` (ไม้เดียว) | เหมือนกัน · เช่น `60/40` |
- ค่าผิด → error + บันทึกไม่ได้ (แบบเดียวกับช่องอื่นใน Sat v2) · ข้างช่องแสดง "= 3 ไม้" / "= ไม้เดียว"
- ค่าเดิมของผู้ใช้: ถ้าเคยตั้ง pyrSplit เดิม (PY2) → map เข้า **แบ่งไม้ Main** · Tactical = `100`
- ไม้ 1 = % แรก ของดีล · ไม้เติมใช้ % ถัดไป · Risk รวมทุกไม้อยู่ใน Risk ต่อดีลของส่วนนั้น (เหมือน PY2)
- **Tactical เติมไม้ได้เมื่อตั้งมากกว่า 1 ไม้** (ใช้ flow เติมไม้ PY2 เดิม) · ตั้ง `100` = ไม่มีปุ่มเติมไม้ (เหมือนตอนนี้)
- ตารางขนาดไม้ในการ์ดแผนบอก "ไม้ 1 · x% ของดีล" ตามค่าของส่วนนั้น · ไม้เดียว = ไม่ต้องแสดงบรรทัดนี้
- แผนออก Tactical (TP1 2R 50% · TP2 3R) คิดจาก Entry ไม้ 1 เหมือนเดิม

## 2. ไม้เติมต้องผ่านเพดานเดียวกับไม้ใหม่ (ปิดช่องโหว่ PV2b)
- ตอนเติมไม้ (Main/Tactical): เช็ก Satellite ≤ 1.2% · ต่อสินค้า ≤ 0.6% · Core+Sat ≤ 6% · Max DD Satellite · (Tactical) เบรก Tactical
- เกิน → **บล็อก** + ข้อความตัวเลขแบบเดียวกับ PV2b (เช่น "Risk XAUUSD จะเป็น $940 > $900 (0.6%)") · ปุ่มเติมไม้ปิด + เหตุผลใต้ปุ่ม

## 3. การ์ด Asset ที่จอแคบ (≤ 600px)
- ตอนนี้แถวไม้ Main/Tactical + แถบ "Risk รวม" อัดอยู่ในการ์ด 2 คอลัมน์ (ชื่อสินค้าตัดบรรทัด `XAUU|SD`) → **การ์ดที่มีไม้ค้าง/รอเข้า ให้กินเต็มแถว (span 2 คอลัมน์)** หรือย้ายแถวไม้ไปเป็นแถบเต็มความกว้างใต้การ์ด (เลือกแบบที่ง่ายกว่า) · ชื่อสินค้าห้ามตัดกลางคำ
- 1440 คงเดิม

## 4. หัว Strategy
- ตัดบรรทัดเดิม `RPT x% · ไม้ Sat n/m` (ค่า RPT เดิมของ Sat) ที่ซ้อนกับค่าใหม่ → แทนด้วย `RPT Main x% · Tactical y%` จากตั้งค่า Sat v2 ของบัญชีนั้น · ส่วนอื่นในบรรทัด (ถัง Sat · DD · heat · ไม้ใหม่) คงไว้
- ห้ามทำให้หัวสูงขึ้น

## 5. ช่องฟอร์มแผน v2
- ช่อง TF · เสริม · Entry · SL · TP (Main) ใช้สไตล์ input เดียวกับช่องอื่นของแอป (ความสูง ≥ 36px ที่มือถือ · มุมโค้ง · ขอบ/สีตามธีม) — ตอนนี้เป็น input ดิบ
- 390: Entry/SL วางคู่กันได้ ไม่ล้น · ป้าย "$ระยะ" อยู่ท้ายแถว

## 6. ตัดบล็อก Trend ในการ์ดแผน v2
- การ์ดแผน **v2 เท่านั้น**: ซ่อนแถว Trend (ปุ่ม ขึ้น/ผสม/ลง · ปุ่ม [เปลี่ยน] · คำเตือน Trend Shift ยาว) — Bias/Trend ตั้งที่ Strategy แล้ว
- ยังแสดงบรรทัดสั้น: `Macro: …` + `ขนาดไม้: เต็ม/ลด x%` (ตัวคูณ Macro ยังทำงาน) · ข้อความบังคับเขียนเหตุผลตอนสวน Macro ยังอยู่
- แผนเดิม (kind bp / ไม่มี v2) แสดงเหมือนเดิมทุกอย่าง
